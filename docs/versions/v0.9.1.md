## 变更（一行写"对使用者有什么变化"，不写"改了哪个文件"）

- **生成项目里的安全扫描不再对自己假报红**（`template/security.ps1`，随包分发）：自身跳过口径从「运行中的那个路径」扩到「逐字节副本」——同一份脚本的两份副本（母版根与 `template/`）不再互为对方眼里的"自己的副本"，恒 5 条 `[红]`、退出码 1 的假红消失。判定用「先比长度、再比 SHA-256」；**内容不同的同名文件照扫**，不给逃逸留口子。
- **母版仓自身的流程文件（不影响已装用户）**：根 `AGENTS.md`（宪法副本，`规则版本：2026-10-05.2`）+ 根 `STATE.md` + `docs/` 骨架（registry 三件套 / TECH_DEBT / lessons）+ 五个守护脚本（`check` / `doctor` / `gate` / `orphans` / `security.ps1`）+ `.tool-versions`。这些路径**不在** `package.json` 的 `files` 里 —— 装走的用户拿到的包，除版本号外与 `0.9.0` 无差别。

## 升级注意

**不适用**（本版无破坏性变更）。逐条对照四行槽位：**影响谁** —— 无（命令参数 / 回执 schema / 目录约定 / Loader 行 id 全未动）｜**怎么迁移** —— 不用迁移，重启 DSH 即生效（或 `npm i -g roadbook@0.9.1`）｜**不迁移会怎样** —— 除版本号外无差别；旧版 `security.ps1` 只会在**母版仓这种"两份同内容副本"的布局**下多报红，生成出来的项目不受影响｜**回滚方式** —— `git checkout v0.9.0`，本版无数据结构变更，数据不用退。
