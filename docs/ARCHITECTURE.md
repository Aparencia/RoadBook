## 2. 分层说明（1-3 卡接入时按真实目录反推；每层一行：放什么）

| 层 | 目录 | 放什么 |
| :-- | :-- | :-- |
| 宿主半（Node ESM） | `lib/`、`plugin/*/` | 插件行的能力逻辑：版本自检、自动更新判定、触发词注入、门禁判定、自进化信号计算；纯逻辑与接线分离 |
| 浏览器半 | `lib/client.js` | 手写 ModuleLoader bundle（无 JSX、无构建步骤）：侧栏「图册」与「自进化」两个标签页；**只读图纸，不改盘** |
| 技能层 | `skills/roadbook/`、`skills/roadbook-atlas/` | 两个 DSH 技能：`SKILL.md` 路由 + 4 个 CLI + vendored 渲染器 |
| 流程知识（数据，非代码） | `playbook/`、`playbook_EN/`、`rules/`、`design/` | 49×2 张卡、规则索引、设计事实源；改它走母版维护口径（双语同批 + `_qc/check.ps1`） |
| 项目模板层 | `template/` | 新项目脚手架：宪法 + `STATE.md` + 五个守护脚本 + `docs/` 骨架 |
| 自检层 | `_qc/`、`test/` | 母版体检、卡行为 baseline、一次性迁移脚本、单测 300 项 |
| 文档层 | `docs/` | 本项目自己的机制配套文档（2026-10-06 由 1-3 卡建立） |

- **无接口层 / 数据层**：不提供 HTTP 服务、不建表。`lib/index.js` 注册的 4 条路由是**同源本机路由**（`/roadbook/update/*`、`/roadbook/evolve/*`），不是对外接口——但**新增这类路由仍触 C3「新增对外接口」红线**，要登记 `docs/registry/APIS.md`。

## 3. 数据流（1-3 卡接入时反推两条真实链路）

**链路 A · 图纸生成（agent 跑）**
1. agent 执行 `node skills/roadbook-atlas/bin/atlas.mjs render <spec>`，spec = `docs/diagrams/*.atlas.json`
2. CLI 调 vendored 渲染器 `skills/roadbook-atlas/vendor/archify`，产出自包含 HTML + `.receipt.json`
3. 三个文件落 `docs/diagrams/`（该目录已 gitignore；要入库须显式 `git add -f`）

**链路 B · 图纸预览（人在侧栏点）**
1. 用户在「图册」标签页点开某张图 → `lib/client.js` 用 `fs.tree` 读到的**绝对路径**发请求
2. 请求打到宿主侧 better-sidebar 的 `/sidebar/html/` 预览路由（服务端已带 CSP sandbox）
3. 宿主读盘回传 HTML → iframe 渲染；图册每 15 秒比对一次 `fs.tree` 名称指纹，变了才重读元信息

- 两条链路**都不经过数据库**；唯一的"存储"是仓库工作树里的文件。

| 要落的东西 | 产物路径 | 谁写（卡号） | 什么时候写 | 验证方式（必须可测） |
| :-- | :-- | :-- | :-- | :-- |
| 非功能需求：性能 / 容量 / 可用性 / 安全 / 可维护 / 兼容 | `docs/specs/<日期>_<slug>/NFR.md`；受影响的模块约束回写本文件 §1~§4 | 2-4 卡（阈值由用户确认） | 范围确认后、动代码前 | 每条给「可测阈值 + 验证方式」（跑什么命令、看哪个指标）；给不出阈值写 `N/A（理由）`，不许留空 |
| 威胁建模：资产 / 入口 / 信任边界 / STRIDE 六类 | `docs/specs/<日期>_<slug>/THREAT.md` | 3-2 卡（触碰认证、支付、删数据、外部接口时必走） | 设计批准前 | 每条威胁给缓解措施，或显式接受并写理由；新发现的红线域改动进 SCOPE 并升 L 档 |
