## 2. 文案外置检查（每加一种语言重跑；4-2 审查按本表抽查）

| 检查项 | 怎么查（可直接复制） | 合格判据 |
| :-- | :-- | :-- |
| 界面文字写死在代码里 | `Select-String -Path src/**/*.vue,src/**/*.ts -Pattern "[\u4e00-\u9fa5]"` | 命中要么是注释，要么是文案键；界面字符串不合格 |
| 各语言文案键齐全 | 比对两份文案文件的键集合 | 缺失键 = 0，且有回退链记录在 §1 |
| 拼接与占位符 | 搜用加号拼句子的写法 | 用格式化函数（占位符），不手工拼句子 |
| 错误提示 | 走查所有失败分支 | 错误提示也走文案键，不出现裸英文或裸中文 |
| 布局膨胀 | 切到最长语言（如德语）看按钮与表格 | 不截断、不重叠、不溢出容器 |

## 3. 可访问性清单（7 条；每条必须写验证方式，7-6 卡逐条给结论）

| 检查项 | 合格判据 | 验证方式 |
| :-- | :-- | :-- |
| 键盘可达 | 全部交互控件可 Tab 到达并激活 | 只用键盘走一遍核心路径 |
| 焦点顺序 | 与视觉顺序一致，焦点环始终可见 | Tab 走查并记录顺序；不用正数 `tabindex` |
| 对比度 | 正文 ≥4.5:1，大字 ≥3:1，UI 边界 ≥3:1 | 跑 `docs/DESIGN_TOKENS.md` §3 的对比度命令 |
| 语义标签 | 按钮/表单/表格用语义元素，不拿 div 冒充 | 看 DOM 结构与无障碍面板的语义树 |
| 替代文本 | 图片有 alt，图标按钮有可读名称 | 逐个图标/图片检查；纯装饰图 alt 留空 |
| 屏幕阅读器 | 核心路径能听懂，朗读顺序正确 | 用系统朗读工具走一遍主流程 |
| 触控目标 | 可点区域 ≥44×44px（含图标按钮） | 量按钮与列表项尺寸，拥挤处加内边距 |

- 不合格怎么办：补语义/补属性/调色值/加内边距；当场修不了就登记 `docs/TECH_DEBT.md` 并写明清偿触发条件。
- 缩放：200% 缩放不丢功能、不出现横向滚动条（改布局，不靠缩小字号糊弄）。
