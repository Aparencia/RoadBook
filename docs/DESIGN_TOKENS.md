## 1. 令牌来源与优先级（宿主变量 → fallback；本项目不自选色）

- 界面 = DSH better-sidebar 的侧栏面板（图册 / 自进化两张标签页）。颜色**不自选**：一律写成 `var(--dsw-alias-<语义>, fallback)`——宿主定义了就用宿主的，宿主没定义才落 fallback；写法见 `lib/client.js:1142`。
- 唯一令牌表 = `lib/client.js:1142-1147` 的 `TOKEN`（6 条）。自进化页经虚拟模块取同一张表（`lib/client-evolve.js:33` = `host.styles.TOKEN`）⇒ 不存在第二处真相。
- **没有自选品牌色，也没有色阶**：配色权在宿主——插件与宿主界面同屏，抢配色就是两套体系，插件只借宿主的语义别名。上一版骨架里的 `--color-brand-*` / `--color-neutral-*` 十阶是模板给新建项目的示例值，本项目一个都没用，已删。
- 实测（复跑方法见 §3 末）：这 6 个名字在宿主安装产物里只有 `--dsw-alias-bg-layer-2` 存在，其余 5 个没有 ⇒ **今天实际渲染的主要是 fallback 值**。改名字属代码侧决定，不在本文档职责内。

## 3. 对比度门禁（谁负责 / 怎么验 / 宿主变量缺失时怎么办）

- **谁负责 = 宿主**：颜色值不由本项目给 ⇒ 本项目不做自选色的对比度承诺（没有自选色可承诺）；宿主换主题时的一致性由宿主主题保证，插件不干预。
- **算不了的两处，写明为什么**：`border` 与 `surface` 的 fallback 是半透明灰（alpha 0.28 / 0.06），比值必须先与宿主底色合成，而宿主底色在仓库内不可知 ⇒ 算不了；`text` 的 fallback 是 `inherit`，它不是色值 ⇒ 无从计算。
- fallback 里三个不透明 hex 只能给"假定底色"下的参考值（白底 / `#1e1e1e` 底）：`#8a8a8a` 3.45 / 4.83｜`#3b82f6` 3.68 / 4.53｜`#d97706` 3.19 / 5.23——**白底三档全部低于 4.5:1** ⇒ fallback 只保证"看得见"，不保证 WCAG AA。
- 宿主变量缺失时怎么办：**不补自选色**。`inherit` 与两个半透明灰本就是"随宿主明暗都成立"的中性表达；已知会低于 AA 的只有上面两个固定 hex 强调色——需要 AA 时应当改用宿主别名，而不是换一个 hex。
- 焦点环：`N/A（焦点环由宿主原生 :focus-visible 提供；两文件 0 处 outline / :focus 规则，本项目不自绘，也不做焦点环对比度承诺）`。
- 怎么验：拿这 6 个变量名到宿主安装产物 `resources/app.asar`（本机 `D:\AISI\Deepseek harness\`）里做字节级查找——命中 = 宿主定义了这个别名，未命中 = 该 fallback 今天生效（§1 的实测就是这么来的）。

## 5. 间距（没有 `--space-*` 令牌，也没有 4px 基线制；值直接写在组件里）

- **4px**：同一行内图标↔文字（`lib/client.js:1153`）、卡片内纵向列间距（`:1217`、`lib/client-evolve.js:214`）、更新区块内列间距（`:1711`）。
- **6px**：同一行内元素之间（工具栏行 `:1182`、卡片头 `:1220`）、列表纵向间距（`:1258`、`:2185`）、更新条 `:1382`、状态文字块 `:2164`。
- **8px**：卡片内边距（`:1217`）、面板根纵向间距（`:2213`、`lib/client-evolve.js:347`）、刷新徽标左外边距（`:1677`）。
- **不是 4px 整倍数的值，如实列出**（实现就是这些值，不改成"符合基线"）：`6px`（上条）｜`10px`（面板根 `padding: 10px` `:2213`；更新区块 `marginTop: 10px` + `padding: 8px 10px` `:1711`）｜`12px`（chunk 兜底消息内边距 `:209`）；紧凑内边距 `2px 8px`（按钮 `:1154`）、`0 6px`（胶囊 `:1169`）、`1px 6px`（刷新徽标 `:1678`）、`6px 8px`（更新条 `:1382`）。
- 为什么可以对不齐网格：面板是宿主侧栏里的窄列，密度优先，实际只用到这几档；本项目从未建立 spacing scale，凭空造一套反而是第二套体系。要加新档 → 回 3-5 立项。

## 6. 圆角、描边与阴影

- **圆角三档**：`6px` 按钮（`lib/client.js:1160`）｜`8px` 卡片 / 更新条 / iframe 外壳（`:1217`、`:1273`、`:1382`、`:1711`、`lib/client-evolve.js:214`、`:236`）｜`999px` 胶囊徽标（`:1172`、`:1680`）。没有 4px 与 12px 档。
- **描边恒 1px**：默认 `1px solid TOKEN.border`（卡片 / 更新条 / 非主按钮 / 胶囊）；主按钮与"正常态"刷新徽标改 `1px solid TOKEN.accent`（`:1159`、`:1679`）；"判不了"的胶囊是 `1px dashed TOKEN.border`（`:1175`）。没有 2px 描边，也没有拿描边冒充的焦点环。
- **阴影 = 零**：`boxShadow` / `textShadow` 在两文件里 0 处。够用的理由：面板是宿主侧栏里的一列，层次只由「8px 圆角 + 1px 描边 + 半透明面填充」表达；没有浮层、下拉、抽屉、模态（见 §9），没有任何元素需要从底面上抬升。宿主主题的阴影也不由插件写死。

## 7. 明暗模式（宿主主题管）

- `var(--dsw-alias-x, fallback)` 命中宿主别名时，明暗切换由宿主换值，插件不写第二套取值 ⇒ 不需要自绘明暗映射表。
- `N/A（无自选色、无自绘明暗映射表：本项目只有一份 fallback 常量，不随明暗变化，明暗一致性由宿主主题负责）`。上一版骨架的亮/暗两列示例值与"暗色六条"已删——本项目一个都没用。

## 8. 命名规则与禁则（本项目新增令牌的规矩）

- 新增颜色：**先问宿主有没有对应 alias**（`--dsw-alias-*`）。有 → 只写 `var(--x)`；宿主没有 → 才写 fallback，且必须写成 `var(--x, #hex)` / `var(--x, rgba(...))` 形式——`lib/client.js:1142-1147` 是唯一允许出现裸 hex 的地方。
- 新增尺寸：直接写 px，**不新造** `--space-*` / `--radius-*` / `--shadow-*` 令牌层（本项目没有这一层，造了就是开第二套体系）。字号只许取 11 / 12 / 13 三档，加档先回 3-5 立项。
- 禁则（违反即作废）：写 `--color-brand-*` / `--color-neutral-*`（模板给新建项目的品牌色阶，母版不选色）｜组件里写裸 hex（当前 0 处）｜只靠颜色表状态（警示色都与文字同现）｜自绘明暗映射表｜写 `--dsw-alias-*` 却核不到（见 §3）。
