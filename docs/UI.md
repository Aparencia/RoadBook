## 2. 状态矩阵（按实现真实存在的态写；8 态里的通用行见本节末）

图册 `roadbook:gallery`：

| 态 | 触发 | 这一刻屏幕上是什么 |
| :-- | :-- | :-- |
| G1 加载 | 首次进入 / 切回标签页且手里没数据 | 一行「正在读取图纸…」；已有数据时不闪空 |
| G2 空 | 目录读完且 0 条 | 「这个目录里还没有图纸」+ 目录路径 + 怎么做 + 可复制的提示词 +［让 agent 生成架构图］［复制提示词］ |
| G3 目录不存在 | 首次使用 / 新项目（`missingDir`） | 「读取失败：<原因>」+「目录不存在（首次生成图纸时会自动创建）」+ G2 那套空态与生成入口 |
| G4 读取失败 | fs 报错且不是目录不存在 | 「读取失败：<原因>」+ 怎么做；不给生成按钮（先修环境，别把人引到错方向） |
| G5 元信息截断 | 条目超过 40 张 | 一行「条目过多，仅读了前 40 张的元信息（列表仍完整）」；列表本身照旧全列 |
| G6 预览中 | 点某行［预览］ | 整块换成 iframe（服务端 CSP + 客户端 `sandbox` 双闸）+［← 返回列表］［打开］［导出］ |
| G7 打包导出 | 点［打包导出］ | 徽标「正在打包…」；失败换「打包失败」徽标 + 失败原因原文（徽标 `title` 也带一份） |
| G8 生成 | 点［让 agent 生成架构图］ | 按钮禁用并变「已交给 agent…」；idle 时按钮下一行说明它在侧聊里跑、画好会自动出现 |
| G9 生成失败 | `sidechat.start` 被拒 | 按钮下「没能唤起 agent：<原因>」 |
| G10 更新条 | 页脚更新条（宿主判定） | 十二种状态之一（检查中 / 可更新 / 已是最新 / 本地领先 / 开发安装 / 正在更新 / 已更新 / 已是最新无需重启 / 更新失败 / 检查失败 / 发起失败 / 暂未检查）；路由不在或 `mode: off` 时整条不渲染 |
| G11 脚本分块 | 自进化页的脚本在路上 / 加载失败 | 「正在加载这个标签页的脚本…」/「这个标签页的脚本没加载成功…」；不留死转圈 |

自进化 `roadbook:evolve`：

| 态 | 触发 | 这一刻屏幕上是什么 |
| :-- | :-- | :-- |
| E1 读取中 | 标签页变为可见 | 一行「正在读取信号…」 |
| E2 宿主路由不在 | 404 / 连不上（status 0） | 「宿主半没有这条路由…」+ 一句怎么办；一个按钮都不留（不放假按钮） |
| E3 读取失败且无旧读数 | 403 / 500 / 形状不合格 | 「读取失败：<原因>」+［重试］ |
| E4 刷新失败但有旧读数 | 同上，但手里有上次读数 | 旧读数照旧显示，列表顶部加一行警告「读取失败：<原因>」 |
| E5 空 | 读数回来了但 `signals` 为空 | 一行「没有信号」 |
| E6 三态 | 每条信号一行 | 标题 + id + 徽标：越界（警告色）/ 正常（中性实线）/ 判不了（中性虚线）；页头三枚计数徽标分开显示 |
| E7 无读数 | 宿主写了正常但没有 reading | 读数位写「无读数」，徽标降成「判不了」（0 是读数，没有是另一回事） |
| E8 重算中 | 点［重算］ | 按钮禁用 + 文案「正在重算…」 |

- 硬口径：verdict 只认字面量 `ok` / `hit`，其余（缺失、大小写不同、宿主将来加的新值）一律「判不了」；没有 tick 记录时活性也降「判不了」——判不了 ≠ 通过。
- 8 态里的通用行：无权限 = 没有自建权限模型，宿主 403 走 E3 / E4 显示原因（不整块降级）；离线 = 不单独判网，请求失败即 E3 / E4；超长文本 = 标题 / 路径 / 错误原文 `word-break: break-all` 换行不撑破；极端数值 = 计数缺失印 `?`、读数缺失印「无读数」，`NaN` 与 `{占位符}` 不上屏。

## 4. 按钮规格表（尺寸只有一档；自定义尺寸 = 破风格）

| 项 | 实测值 |
| :-- | :-- |
| 内边距 / 字号 / 行高 / 圆角 / 内部 gap | `padding: 2px 8px` · `fontSize: 12px` · `lineHeight: 18px` · `borderRadius: 6px` · `gap: 4px`（图标与文字之间） |
| 边框 / 底色 / 光标 | `1px solid`（primary 用 `TOKEN.accent`，其余用 `TOKEN.border`）· 透明底 · `cursor: pointer` |
| 禁用态 | 只有 `disabled` 属性（生成中 / 重算中 / 检查中），不自绘第二套样式 |
| 图标位 | N/A（没有图标按钮，按钮里只有文字） |

- 触控目标算法：像素高度 ≈ `lineHeight 18 + padding 上下 2×2 + border 上下 1×2 = 24px`；宽度随手心文字走。
- 结论：**不达标**——24px < 44×44 pt，相邻按钮间距 6px（`sectionStyle` 的 `gap`）也不达 8px；影响面是桌面侧栏（指针操作为主），真出现触控宿主或 7-1 有 UI 改动批次时随 better-sidebar 一起处理，本轮不单方面加高（会与宿主既有控件不同高）。

## 7. 键盘与焦点顺序

- Tab 顺序 = DOM 顺序 = 视觉顺序：全部原生 `button` / `a`，全库没有 `tabindex`。
- Esc / Enter：N/A（无自绘弹层、无 keydown 监听；Enter 走浏览器默认的按钮激活）。

## 8. 微文案

- 文案唯一出处 = locale 字典的中英两份同键表（`dict(ctx)` 查表）；界面上不硬编码中文，也不把内部字段名留给用户。
- 空值兜底与句式：宿主只给原因码时先过一层兜底文案（`{reason}` 空串换成「未知原因」，占位符原样上屏等于把内部字段漏出去）；错误句一律「发生了什么：为什么」（如「读取失败：<原因>」「没能唤起 agent：<原因>」）；按钮用动词短语（预览 / 打开 / 导出 / 重算 / 重试）。

## 9. 交互五态矩阵

- default / hover / focus / active / disabled：前四态不自绘，只给静态内联样式（`cursor: pointer`），悬停与按下的观感用浏览器默认；`disabled` 用属性表达（生成 / 重算 / 检查更新），浏览器自己变灰，全库无 `transition`、无动画。
- 状态差异用徽标色调与实线 / 虚线表达（越界 = 警告色，判不了 = 中性虚线），不用动画。

## 10. 触控与目标尺寸

- 实测可点高度 24px（算法见 §4），不达 44×44 pt；相邻按钮间距 6px 也不达 8px——桌面指针场景的现状，处理时机见 §4。
- 输入框高度：N/A（本项目自绘界面里没有输入框；唯一输入由宿主设置页渲染）。

## 11. 图标、数字与标点

- 图标只有自绘 SVG 两个（图册 / 自进化），统一 `viewBox 0 0 24 24`、`strokeWidth 1.6`、`strokeLinecap/Linejoin: round`、默认 16px（尺寸由宿主传入）；不用 emoji 当图标。
- 数字与标点：字节数走 `formatBytes`（B / KB / MB），时间走 `formatTime`（`YYYY-MM-DD HH:mm`）；计数缺失印 `?`、读数缺失印「无读数」；省略号用单字符 `…`，引用用「」。
