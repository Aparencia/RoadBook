# feedback/ · 反馈回流收件箱（母版与派生项目同一份契约）

> 最近核对 2026-10-07 @ 4384acc（本目录首次落地，台账 #23 / 反馈根因 D）
> 谁写：任何派生项目 / 本项目会话（发现母版的卡、判据、脚本、文档与现实不符时）｜ 谁读：6-6 流程体检、4-1 分批编码、5-1 归档、人
> 为什么有它：`RISK.md` 的证据生命周期链末环写的是「回流（`feedback/`）」，而 `feedback/` 此前只是四个字、磁盘上没有这个目录——本目录把那一环落成可核对的形态。
> 与近似物的分界（D6 禁平行新建）：`docs/pool/IDEAS.md` = 本项目自己的新想法；`docs/TECH_DEBT.md` = 已知欠账与清偿条件；`docs/reviews/` = 本项目的质量报告；**本目录 = 别处回到母版的证据**（现象 + 命令与输出原文 + 期望），一条一个文件。

## 一条反馈 = 一个文件

- 文件名：`YYYY-MM-DD_<slug>.md`（slug 小写连字符，如 `2026-10-07_route-bom.md`）；**文件名里的日期必须等于字段行里的 `日期`**（同一事实两处写，就按同源判）。
- 写法：复制 `TEMPLATE.md` 改名再填；`README.md` / `TEMPLATE.md` / `INDEX.md` 是保留名，**不许**往里追加条目（保留名里的内容是人读契约，不是收件箱内容）。
- 字段行 = 正文第一行，五格用全角 `｜` 分隔、`键：值` 用全角冒号：

```
> 日期：2026-10-07 ｜ 来源：<项目或人>@<短哈希> ｜ 轴：判据 ｜ 状态：new ｜ 落点：—
```

| 字段 | 取值 | 机器怎么判（`feedback.mjs --check`） |
| :-- | :-- | :-- |
| 日期 | `YYYY-MM-DD` | 格式错、或与文件名不一致 = 红 |
| 来源 | `<项目或人>@<短哈希>` | 空 = 红 |
| 轴 | `卡片` / `判据` / `仪器` / `文档` / `流程` / `其他` | 词表外 = 红（不新增同义词，就近改这一行） |
| 状态 | `new` / `triaged` / `landed` / `killed` | 词表外 = 红 |
| 落点 | 卡号 / `文件:行` / `—` | 状态 `landed` 却写 `—` = 红（落了地就必须指得出落在哪） |

- 三个必填小节（标题在位**且**内容非空）：`## 现象`（只写看到的事实，不是判断）、`## 命令与输出原文`（复现命令 + 输出**原文**；纯人读观察写「无命令：<在哪看到的>」）、`## 期望`（期望行为；涉卡就写卡号与那一条）。可另加 `## 影响面`。
- **为什么不用 YAML front matter**：本仓零运行时依赖，而 YAML 的 `键: 值` 一旦值里出现 ASCII 冒号加空格就会被读成嵌套映射（`SKILL.md` 那条 frontmatter 教训：宿主静默丢掉整份技能）；一行五格用全角分隔符，正则就能判，不需要 YAML 解析器。

## 怎么回流（单人档：不假装有自动通道）

1. 派生项目在**自己的** `feedback/` 里写好条目（格式同上；`template/feedback/` 随模板分发，两处与本页逐字节相同）；
2. 人把条目文件**原样复制**进母版 `feedback/`（文件名与字段一个字都不改；复制进来的那一刻它就是母版收件箱里的条目）；
3. 母版 `node skills/roadbook/bin/feedback.mjs --check` 判绿 → 4-1 分批编码把它排进某一批 → `状态` 从 `new` 走到 `landed` 时把落点写实。

**明确不做**（方案 §7）：通用化成多项目反馈平台、做自动同步通道、把条目内容塞进任何卡的判据里——先做最小回流。

## 渲染与判据

| 命令 | 干什么 | 退出码 |
| :-- | :-- | :-- |
| `node skills/roadbook/bin/feedback.mjs` | 默认 = `--check`：逐条校验字段、命名、三小节，并打印计数 | 0 判绿 / 1 判红 / 2 用法错 |
| `node skills/roadbook/bin/feedback.mjs --index` | 校验后打印派生索引（与 `--write` 写出的文件逐字节相同） | 同上 |
| `node skills/roadbook/bin/feedback.mjs --write` | 同上，并把索引写进 `feedback/INDEX.md` | 同上 |
| `node skills/roadbook/bin/feedback.mjs --dir <路径>` | 换收件箱目录（测试与派生项目用） | — |

`INDEX.md` 是**派生视图**：条目文件是唯一真相，手改索引下次渲染就没了（所以默认不生成，人不看就不写盘）。条目入库走 D13：结论落 `docs/decisions/` 或 `docs/TECH_DEBT.md`，本目录只留证据本身——**任一环只放指针不放原文 = 引用一段将来不存在的东西**。
