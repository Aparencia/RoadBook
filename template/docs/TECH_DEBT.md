# TECH_DEBT · 技术债台账（唯一债务账本）
> 用法：一切"欠着的事"都在这——顺手问题、被否方案、无法复现的 Bug、清理事项。
> 状态机：open（欠着）→ carried（滚入下期，只留一行摘要）→ closed（已偿还，**必须附证据**：commit/文件路径）。关闭不附证据 = 没关闭。
