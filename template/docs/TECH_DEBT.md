# TECH_DEBT · 技术债台账（唯一债务账本）
> 用法：一切"欠着的事"都在这——顺手问题、被否方案、无法复现的 Bug、清理事项。
> 状态机：open（欠着）→ carried（滚入下期，只留一行摘要）→ closed（已偿还，**必须附证据**：commit/文件路径）。关闭不附证据 = 没关闭。
> 每条债必须写清四项：位置（文件:行 或 模块）、类型（腐化/设计/测试/依赖/文档）、影响（不还的后果）、清偿触发条件（什么信号出现就该还）。
> 腐化类条目筛选关键词：`_old`、`_legacy`、`_v2`、`Deprecated`、`暂时保留`、`废弃`、`TODO: 删`——7-3 清偿卡的扫描命令照这组词搜源文件，命中即登记一行。
