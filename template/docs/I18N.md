# I18N · 语言、区域与可访问性（7-6 卡产物；≤60 行）
> 谁创建：7-6 国际化与可访问性 ｜ 谁维护：7-6（加语言或区域、改文案来源、可访问性清单变动时）｜ 何时更新：新增语言或区域、把写死的文案搬进文案文件、可访问性问题被修复或新发现
> 不适用时怎么写：只有一种语言且无区域差异（日期、货币、时区都不用区分）→ 各节写一行 `N/A（理由）`，**不许整份不建**；理由要能判定，例：`N/A（单语言内部工具，仅本地时区）`。

## 1. 语言与区域表（7-6 卡逐个支持的语言填；没填的语言 = 不支持）

| 语言/区域代码 | 覆盖范围 | 文案文件 | 是否默认 | 谁在维护 |
| :-- | :-- | :-- | :-- | :-- |
| <如 zh-CN> | <全部界面 / 仅核心路径> | <src/locales/zh-CN.json> | 是 | <人名/角色> |
| <如 en-US> | <核心路径> | <src/locales/en-US.json> | 否（回退 zh-CN） | <人名/角色> |

- 区域格式：日期与时间、货币、数字千分位、时区、一周起始日——逐项写"跟随系统区域"还是"固定某个值"，固定值要写理由（7-6 卡填）。

## 2. 文案外置检查（4-2 审查卡按本表抽查；每加一种语言重跑）

| 检查项 | 怎么查（可直接复制） | 合格判据 |
| :-- | :-- | :-- |
| 界面文字是否写死在代码里 | `Select-String -Path src/**/*.vue,src/**/*.ts -Pattern "[\u4e00-\u9fa5]"` | 命中要么是注释，要么是文案键；界面字符串不合格 |
| 各语言文案键是否齐全 | 比对两份文案文件的键集合 | 缺失键 = 0；有回退链且记录在 §1 |
| 拼接与占位符 | 搜用加号拼句子的写法 | 用格式化函数（占位符），不手工拼句子 |
| 错误提示 | 走查所有失败分支 | 错误提示也走文案键，不出现裸英文或裸中文 |
| 布局膨胀 | 切到最长语言（如德语）看按钮与表格 | 不截断、不重叠、不溢出容器 |

## 3. 可访问性清单（每条必须写验证方式；7-6 卡逐条给结论，4-2 卡抽查）

| 检查项 | 什么时候查 | 验证方式（可直接复制或按步骤走） | 不合格怎么办 |
| :-- | :-- | :-- | :-- |
| 键盘可达 | 每次改交互控件 | Tab 走查：全部控件可达、焦点可见、顺序合理 | 补 `tabindex` 或改语义标签；登记 docs/TECH_DEBT.md |
| 对比度 | 每次改颜色 | 用对比度检查工具，正文 ≥ 4.5:1，大字 ≥ 3:1 | 调色值，不靠加大字号糊弄 |
| 语义与替代文本 | 每次加图片/图标/表单 | 图片有 alt；表单控件有关联 label；图标按钮有可读名称 | 补齐属性 |
| 屏幕阅读器 | 核心路径 | 用系统朗读工具走一遍主流程，能听懂 | 修语义结构或补 `aria-*` |
| 缩放与动效 | 每次改布局 | 200% 缩放不丢功能；动效可关闭 | 改布局；`prefers-reduced-motion` 兜底 |

- 收尾：本文件任一改动，同批更新 `docs/registry/COMPONENTS.md` 的「可访问性」标注；提交前跑 `powershell -NoProfile -File check.ps1` 取退出码 0。
