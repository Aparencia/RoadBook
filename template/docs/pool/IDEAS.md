# IDEAS · 需求池
> 用法：一切想法先进池（驱动卡自动登记），不打断当前工作；启动某个想法 = 复制驱动卡后说"启动 <想法>"。
> 状态：idea（随口想法）→ researching（调研中，链 specs）→ done（已实现，链 commit）/ killed（死亡，必须写复活条件）

| 日期 | 想法 | 状态 | 复活条件 / 结论 |
| :-- | :-- | :-- | :-- |
| （示例）2026-01-10 | 支持导出 Excel | idea | 有 3 个用户问起就启动 |
| （示例）2026-01-12 | 做手机 App | killed | 立项调研判 Kill：单人维护双端成本超预算；复活条件：Web 版日活 >50 |
