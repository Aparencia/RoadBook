## 3. 组件选择表（先选层级再画样式；同级按钮同屏 ≤1 个）

| 场景 | 用什么 | 层级/变体 | 不用什么 |
| :-- | :-- | :-- | :-- |
| 主操作（提交、保存、下一步） | Button | primary，同屏 1 个 | 不用多个 primary 抢焦点 |
| 次操作（取消、返回、预览） | Button | secondary | 不用纯文字冒充主按钮 |
| 低频或第三操作 | Button | tertiary（文字按钮） | 不用它放破坏性动作 |
| 删除、不可逆动作 | Button | danger + 二次确认 | 不与 primary 并排紧贴 |
| 输入 | Input / Select / Textarea | 标签在上，见 §5 | 不用 placeholder 当标签 |
| 导航 | Tabs / 侧栏 / 面包屑 | 同级用 Tabs，跨层用面包屑 | 不用下拉菜单装导航 |
| 反馈 | Toast（成功）/ Inline alert（错误）/ Dialog（必须打断） | 按打扰程度选 | 不用 Dialog 报成功 |

## 4. 按钮规格表（尺寸只有三档；自定义尺寸 = 破风格）

| 尺寸 | 高度 | 圆角 | 图标位 | 内边距 | 用在哪 | 禁用态 | 加载态 |
| :-- | :-- | :-- | :-- | :-- | :-- | :-- | :-- |
| sm | 32px | 4px | 16px | 8px | 表格行内、工具栏 | 透明度 40% + 禁用鼠标 | 图标换转圈，宽度不变 |
| md | 40px | 8px | 20px | 12px | 表单主按钮（默认） | 同上，并保留可读对比度 | 文字换「处理中…」，防重复点击 |
| lg | 48px | 12px | 20px | 16px | 落地页、移动端主操作 | 同上 | 同 md |

- 图标按钮必须有可读名称（`aria-label`），只放图标的按钮触控目标 ≥44px；加载态只换内容不换宽度，宽度跳动会让人点错。

## 5. 表单规则（标签位置 / 校验时机 / 错误位置，三处不许自创）

| 规则 | 定法 | 为什么 |
| :-- | :-- | :-- |
| 标签位置 | 字段上方，左对齐；不用 placeholder 当标签 | 长标签不换行；填完还能看见自己在填什么 |
| 校验时机 | 失焦校验单字段 + 提交时校验全部 | 边打字边报错会打断输入 |
| 错误位置 | 字段下方紧贴，红色文字 + 图标；不与标签同行 | 用户找不到错误 = 报错等于没报 |
| 必填标记 | 标签后加 `*` 并在表单顶部说明；可选字段标「选填」 | 只标一种，别同时标必填和选填 |
| 错误文案 | 照 §8 模板：发生了什么 + 为什么 + 怎么办 | 统一口径，7-6 卡才能外置成文案键 |

## 6. 响应式断点（三档；触控目标 ≥44px 是硬线）

| 断点 | 布局 | 导航 | 表格 | 触控/字号 |
| :-- | :-- | :-- | :-- | :-- |
| ≤640px | 单列，卡片堆叠 | 底部导航或抽屉 | 表格改卡片列表，或横向滚动 | 主按钮全宽，触控目标 ≥44px |
| 641–1024px | 两列，内容优先 | 可折叠侧栏 | 横向滚动 + 首列冻结 | 与桌面同字号，间距收一档 |
| ≥1025px | 多列，最大内容宽 1200px | 常驻侧栏 | 完整表格 + 分页 | 正文 16px 起（见 DESIGN_TOKENS.md） |

**四宽度验证记录（320 / 375 / 414 / 768，每档真跑一次并留记录，不许推断）**

| 宽度 | 判据 | 记录（日期 + 结论） |
| :-- | :-- | :-- |
| 320px | 无横向滚动、主按钮全宽、触控目标 ≥44px | 待填（3-4 卡） |
| 375px | 无横向滚动、正文不挤成单字、输入框不被键盘遮住 | 待填（3-4 卡） |
| 414px | 同 375，多列区显式单列（不靠自动换行凑） | 待填（3-4 卡） |
| 768px | 两列成立、导航不重叠、表格不塌成一条 | 待填（3-4 卡） |

- 防溢出三件套写进样式：`minmax(0,1fr)`、`overflow-wrap: anywhere`、`overflow-x: clip`；视口高度用 `min-height: 100dvh`（不用 `100vh`，移动端地址栏会吃掉一截）。

## 7. 键盘与焦点顺序（每次改交互控件都要走一遍）

| 项 | 定法 |
| :-- | :-- |
| Tab 顺序 | 与视觉顺序一致：从上到下、从左到右；不用正数 `tabindex` 硬改 |
| Esc | 关闭最上层弹层（Dialog / 抽屉 / 下拉），焦点还给触发它的控件 |
| Enter | 在表单里提交主操作；在按钮上等同点击 |
| 焦点环 | 始终可见：`outline: 2px solid var(--color-focus); outline-offset: 2px`，延迟 0ms；不许 `outline: none`，也不许用 `box-shadow` 冒充 |

- 焦点环对所在背景的对比度 ≥3:1；用 `:focus-visible` 让鼠标点击不出环，键盘 Tab 必出环。
- 状态切换（hover/active/disabled）不许改 `border-width`、`padding`、`height`——尺寸一变就会抖。

## 8. 微文案模板（按钮=动词开头；错误=发生了什么+为什么+怎么办）

| 场景 | 模板 | 例 1 | 例 2 |
| :-- | :-- | :-- | :-- |
| 按钮 | 动词 + 对象，≤6 字 | 「保存草稿」 | 「删除记录」 |
| 错误 | 发生了什么 + 为什么 + 怎么办 | 「保存失败：网络断了，请检查网络后重试」 | 「邮箱格式不对：缺少 @，请改成 name@example.com」 |
| 空态 | 一句为什么空 + 一个行动 | 「还没有任务，点「新建」加第一条」 | 「没有匹配结果，换个关键词试试」 |
| 成功 | 做了什么 + 下一步 | 「已保存，可继续编辑」 | 「已发送，等待对方确认」 |
| 危险确认 | 后果 + 是否可逆 + 动词按钮 | 「删除后无法恢复，确认删除这条记录？」 | 「停用后用户无法登录，确认停用？」 |

## 9. 交互五态矩阵（每个可交互元素五行；缺一行 = 该元素没设计完）

| 态 | 触发 | 必须有的表现 | 禁止 |
| :-- | :-- | :-- | :-- |
| default | 静止 | 与相邻元素尺寸对齐（输入框高度 = 相邻按钮高） | 靠颜色单独区分主次 |
| hover | 鼠标悬停 | 变化写进 `@media (hover: hover)`；键盘聚焦有等价表现 | 触屏设备上残留悬停态 |
| focus | Tab 到 | 见 §7 焦点环规格（0ms、始终可见） | 用 outline 之外的位移代替焦点提示 |
| active | 按下 | 位移或缩放在 80–120ms 内完成，且不改变元素占位 | 长于 150ms 的按压反馈 |
| disabled | 不可用 | 三通道同时变：透明度 + 鼠标样式 + `aria-disabled` | 只降透明度（色弱与读屏都看不出） |

## 10. 触控与目标尺寸（三口径同时成立）

- Web 可点区域 ≥24 CSS px、触控目标 ≥44×44 pt（Android 48×48 dp）、相邻可点元素间距 ≥8px；图标按钮/关闭按钮/复选框的实际命中区按此兜底（视觉可以更小，命中区不许更小）。

## 11. 图标、数字与标点（一处风格不一致 = 返工）

- 图标只用一个库、一种 `strokeWidth`；禁止 emoji 当界面图标；每个图标按钮有 `aria-label`。
- 数字对齐用 `tabular-nums`；引号用真引号（""），省略号用单字符 `…`，不用三个点；禁止装饰性外壳（假窗口边框、假浏览器条、假终端提示符、无因渐变）。
