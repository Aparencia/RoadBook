# DATA_DICT · 数据字典
> 用法：建表/改字段前先查；改完必须回写（设计卡更新，归档卡核对）。
> 敏感度：D1 公开 / D2 内部 / D3 敏感个人信息（PII）/ D4 机密——D3/D4 字段加密存储+日志脱敏。
> **怎么填**：每张真实表一节，标题写「表名（中文）」（如 `## bills（账单）`）；没有数据库的项目保持原样即可，不用建节（不是欠账）。
