## ② 执行

**归档十一查（逐条执行，逐条回执；S 档任务：十一查仍逐条执行，但回执合并为一段知会）：**

**① registry 回写核对（diff 驱动，禁止凭记忆回答"改过吗"）**：
   - a. 从 STATE.md 读 `起点锚点` 赋值给 `$anchor`；跑 `git diff --name-only "$anchor..HEAD"` + 变更符号提取 → **变更清单**（ground truth）
   - b. 清单按域分类（UI/表/接口/配置/依赖），每个变更项 → registry 对应行标记：已回写 ✓ / 不适用 —（原因）/ 未处理 ○（**当场补**，○ 不许留空）

**② 教训沉淀**：本次踩坑了吗？有 → 写 `docs/lessons/<日期>_<主题>.md`（≤12 行：现象→根因→修法→下次怎么定位）。**先查重**：同症状更新旧卡，不建新卡。

**③ 债务滚动**：新债务/被否方案 → 登记 `docs/TECH_DEBT.md`（open）；本次已清偿的 → 改 closed 并附证据（commit 哈希/文件路径）。
- **妥协点收口（归档前最后一道，S6）**：本任务改过的文件里还留着的妥协点，归档时必须全部落账——跑
```powershell
Select-String -Path <本任务涉及的文件> -Pattern 'ceiling:|upgrade:|no-trigger'
```
Expected：末行形如 `<N> markers, <M> with no trigger.`（N/M 为真实数字），连同处置计数（登记 TD x / 进未决问题 y / 本批已闭合 z）原样进回执。
  每一条要么在本批落进 `docs/TECH_DEBT.md`、要么写进 STATE.md 的 `未决问题`；**`no-trigger`（没写升级触发条件的那种）排最前**——没有触发条件的妥协点不会自己浮上来，是最先静默腐烂的一类。回执照抄脚本输出末行的 `<N> markers, <M> with no trigger.` + 处置计数（登记 TD x / 进未决问题 y / 本批已闭合 z）。
  ❌ 反例：归档时只说"代码里有些 TODO"，不报条数也不落账（下一轮谁也找不到它们在哪儿）｜✅ 正例：`7 markers, 3 with no trigger.` → 3 条 no-trigger 全部登记为 TD-021~023，其余 4 条进 STATE.md 未决问题。

**④ 版本记录**：根 `CHANGELOG.md` 顶部"未发布"节追加一行（新增/变更/废弃/修复 四类之一，一行一条）。

**⑦ 工作区清理（归档 git mv；目录命名统一 `<日期>_<slug>`）**：
```powershell

$rows    = Select-String -Path docs/TECH_DEBT.md -Pattern '^\|\s*TD-' | ForEach-Object { $_.Line }
```
