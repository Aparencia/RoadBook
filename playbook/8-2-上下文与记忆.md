# 卡 8-2 · 上下文与记忆（长任务/上下文吃紧时读）
> 触发：任务跨多轮、上下文快满、写记忆、或要把工作交接给新会话。 ｜ 产物：`STATE.md` 交接三件 + 记忆条目。 ｜ 下一张：回当前档位主线（S→4-1 / M→2-x 或 4-1 / L→3-1；事故线→6-1）。

---

## ① 开工确认

先回执四行，缺一行不许动手：

1. 当前任务与所在卡（复述一句）+ 已经跑了几轮。
2. 上下文水位：估个百分比；超过一半就先把「动作 2」做完再继续。
3. 本次要写的记忆条目（一行一条，没有就写「无」）与落点（用户偏好 / 项目事实）。
4. 交接对象：本卡收尾是给同一会话续跑，还是给新会话（新会话必须三件齐）。

---

## ② 执行

### 动作 1 · 认四层事实源（读之前先知道谁说了算）

| 层 | 装什么 | 权威性 | 怎么用 |
| :-- | :-- | :-- | :-- |
| 会话窗口 | 本轮说过的话、工具输出 | 最易失真 | 只当草稿；结论必须落进下面三层之一 |
| 热记忆（`USER.md` / `MEMORY.md`，`mnemon_runtime_memory` 读写） | 用户偏好、稳定事实 | 偏好以用户为准；事实可能过期 | 开工自动可读；写入门槛见动作 3 |
| 项目文档（mnemon documents） | 可复用的项目知识 | 有历史，但不保证最新 | 历史决策与旧规则用 `mnemon_recall` / `mnemon_document_search` 检索 |
| 仓库文件（代码、`STATE.md`、`docs/`） | 当前真实状态 | **唯一事实源** | 任何声明前打开确认，冲突时以仓库为准 |

❌ 凭上一轮聊天记忆写「函数已经改好了」。 ✅ 打开文件确认后再写。
❌ 记忆与仓库冲突时听记忆的。 ✅ 以仓库为准，并把过期记忆改掉或删掉。

### 动作 2 · 压缩（该压就压，摘要四项缺一条等于白压）

什么时候压：上下文过半、一个阶段（一批文件/一张卡）收尾、换话题、跑完一个输出很长的命令。

压缩摘要必须含：

1. 全路径 + 行号（每个关键文件写到行）。
2. 原文关键句（判据、错误原文、命令口径照抄，别转述）。
3. 决策与理由（为什么选 A 不选 B）。
4. 未完成项（还没做完的事、等谁回话、下一步动作）。

```powershell
# 压缩前先落盘关键证据，别只留在会话里
Get-ChildItem -Path 'docs' -Filter '*.md' | Select-Object -First 5 Name, Length
```

❌ 只写「大致改了几个文件」。 ✅ 写 `docs/RUNBOOK.md:31` 这类可回查的位置。
❌ 压缩后再回头翻原始输出（已经没了）。 ✅ 压之前把证据先落进文件。

### 动作 3 · 记忆写入规则（宁少勿滥）

只写两类：① 用户偏好与硬规则（谁是用户、怎么沟通、明确说过的「要/不要」）；② 稳定事实（项目约定、环境坑、决策与理由、可复用教训）。

不写：问题、猜测、临时进度、完成日志、从记忆/文档里读出来的证据、密钥。

写入前先查重：已有条目能改就不要新增；纠正旧条目用替换，撤回用删除。一次性小事实标低优先级，明确说过的必须遵守的规则标高。

工具分工：会话级热记忆用 `mnemon_runtime_memory`；长期留存的洞察用 `mnemon_remember`；可复用的大块知识用 `mnemon_document_create` 建项目文档。凭据、令牌一律不写。

❌ 把「已读完 FIX-SPEC」写进记忆（临时进度）。 ✅ 只写会长期复用的约定。
❌ 把检索出来的证据原样回写进记忆。 ✅ 读完即用，不复制。

### 动作 4 · 交接三件（换会话/换机器前必须齐）

1. `STATE.md` `下一步`：写清「执行哪张卡 + 卡名」，不写「继续之前的工作」。
2. `STATE.md` `最近归档`：最近一次收尾的日期 + 做了什么 + 提交哈希。
3. `STATE.md` `未决问题`：等用户裁决的事逐条列，写清选项与影响。

三件齐了再收工；新会话第一句就是「读 `STATE.md`，从 `下一步` 那张卡开工」。

❌ 交接只说「上下文我讲过了」。 ✅ 三件写在 `STATE.md` 里，新会话自己读得到。
❌ `下一步` 留空或写「待定」。 ✅ 写具体卡号与卡名。

### 动作 5 · 长任务（goal 持续轮次 + 里程碑回执）

超过一轮的活：先建 goal（一句话目标 + 完成判据），再按里程碑走——每个里程碑收尾给一次回执（做了什么 / 证据 / 下一里程碑 / 是否还满足完成判据）。

目标达成 → 标记完成；连续三轮被同一件事卡住 → 标记阻塞并写出那件事，而不是继续硬跑。

❌ 用 goal 当"自动继续"绕开每轮回执。 ✅ 每轮都留里程碑回执。
❌ 目标变了还挂着旧 goal。 ✅ 目标变了先改 goal 再继续。

### 动作 6 · 隐私与凭据

- 密钥、令牌、连接串只进 `.env`（已被忽略），不进会话、不进记忆、不进提交。
- 任何日志/截图/回执里都不粘贴真实凭据；泄露过的立即作废轮换。
- 记忆条目只写「凭据放在哪」，不写凭据本身。

### 动作 7 · 自检命令（复制跑）

```powershell
$s = Get-Content 'STATE.md' -Encoding UTF8
foreach ($k in @('## 下一步','## 最近归档','## 未决问题')) {
  if ($s -match [regex]::Escape($k)) { "OK $k" } else { "MISS $k" }
}
$s | Select-String -Pattern '执行哪张卡' | Select-Object -First 1
powershell -NoProfile -File check.ps1
```

判据：三个 `OK` + `下一步` 行有卡号卡名 + `check.ps1` 退出码 0。缺一条 = 交接没做完。

**禁令（违反任一条 = 本轮输出作废）**

- 不许用会话记忆代替打开文件确认。
- 不许把密钥、令牌写进上下文、记忆或仓库。
- 不许把「上下文快满」当借口省掉压缩摘要四项。

边界声明：本卡不选档位、不改主线顺序；只在长任务、上下文吃紧或交接时加走。

## ③ 证据回执

只认三种证据：真实命令输出 / 文件路径 / 提交哈希。逐条给：

1. 上下文水位判断依据 + 压缩发生在哪一步。
2. 压缩摘要落点（文件路径 + 行数）或摘要本身。
3. 记忆条目：写了哪几条、落在哪个文件、为什么不算临时进度。
4. 交接三件：`STATE.md` 三处行号 + 内容关键行。
5. 自检命令输出（三个 `OK` 与 `check.ps1` 退出码）。

---

## ④ 状态回写

1. 先回写：`STATE.md` `最近归档` 补一行（日期 + 做了什么 + 提交哈希）；`未决问题` 逐条更新；`下一步` 换成真正要执行的那张卡。
2. 本卡不改主线指针，除非它改动了主线产物；三件之外不顺手重写别的字段。
3. 再提交：`git add -A`，`git commit -m "8-2 docs(memory): 交接三件与记忆条目"`。
4. 最后复跑 `powershell -NoProfile -File check.ps1` 取退出码 0。
