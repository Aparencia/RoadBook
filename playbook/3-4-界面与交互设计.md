## ② 执行

**动作 1：屏幕清单（做每屏前先记一行；四列缺一不可）**

| 屏幕 | 目标（一句话） | 入口 | 出口／依赖 |
| :-- | :-- | :-- | :-- |
| 例：任务列表 | 让用户在 3 秒内找到上次的任务 | 首页主按钮 | 点行 → 详情；依赖列表接口 |

**动作 2：八态矩阵（每个列表／表单／详情都要过一遍；ID 只用于自检引用）**

| ID | 状态 | 判据（什么时候是它） | 画法 |
| :-- | :-- | :-- | :-- |
| S1 | 空态 | 请求成功但 0 条数据 | 一句说明 + 一个主按钮；禁止只留白 |
| S2 | 加载态 | 请求发出到返回 | 首屏骨架屏；局部转按钮内 spinner；超 1 s 才显示 |
| S3 | 错误态 | 请求失败或校验不过 | 写清发生了什么 + 为什么 + 怎么办，给重试按钮 |
| S4 | 成功态 | 写操作返回成功 | 就地反馈（Toast 3 s 或行内勾）；不弹全屏 |
| S5 | 无权限 | 返回 401/403 | 说明缺哪个权限、找谁开；不给空白页 |
| S6 | 离线 | `navigator.onLine` 为 false | 顶部条提示 + 禁用写操作 + 保留只读缓存 |
| S7 | 超长文本 | 单字段超 200 字符或含无空格长串 | 截断 2 行 + 悬浮显示全文；长串强制换行 |
| S8 | 极端数值 | 0、负数、超 1 亿、空数组 | 先定义显示口径（如 ≥1 万显示 1.2 万）；禁止超框 |

❌ 反例：只画了有数据的样子，空表和 500 错误到上线才第一次见
✅ 正例：八个状态各截一张图放进 docs/UI.md，S7 用 300 字无空格串实测

**动作 3：组件选择表（按层级选，不按喜好选）**

| 类别 | 可选项 | 什么时候选 |
| :-- | :-- | :-- |
| 按钮 | primary / secondary / tertiary / danger | 一屏最多 1 个 primary；次要动作用 secondary；表格内操作用 tertiary；删除等不可逆用 danger 且要二次确认 |
| 输入 | 文本框 / 数字框 / 日期选择 / 单选 / 多选 / 开关 / 文件上传 | 选项 ≤5 用单选，>5 用下拉；二值且即时生效用开关；其余用文本框 |
| 导航 | 顶栏 / 侧栏 / 面包屑 / 标签页 / 分页 / 搜索框 | 一级导航 ≤7 项用顶栏；层级 >2 加面包屑；列表 >50 行加分页 |
| 反馈 | 行内提示 / Toast / 告警条 / 字段错误 | 字段级错误写字段下方；全局结果用 Toast 3 s；需常驻的用告警条 |

**动作 4：按钮规格表（三档，直接抄进样式变量）**

| 档位 | 高度 | 圆角 | 图标位 | 内边距 | 用例 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| 小 | 32 | 4 | 16 | 8 | 表格行内、工具条 |
| 中 | 40 | 8 | 20 | 12 | 表单主按钮（默认档） |
| 大 | 48 | 12 | 20 | 16 | 移动端主操作、引导页 |

禁用态：整块透明度 0.4，`cursor: not-allowed`，不响应点击。加载态：按钮内 spinner，文案改进行时（例：保存 → 保存中），宽度不跳。
❌ 反例：加载时按钮变窄导致旁边元素位移
✅ 正例：`min-width` 锁死当前宽度，只换内容和 spinner

**动作 5：表单规则（五条写死）**
1. 标签在上（不用 placeholder 当标签）；2. 必填加 `*` 并在表单顶部注明 `* 为必填`；3. 校验时机 = 失焦 + 提交（输入中不报错）；4. 错误位置 = 字段下方，紧贴输入框；5. 错误文案禁止只写"输入有误"。

**动作 6：响应式断点（三档，先写手机档）**

| 断点 | 布局 | 主操作 |
| :-- | :-- | :-- |
| ≤640 | 单列；导航收进汉堡菜单 | 底部固定整宽按钮 |
| 641–1024 | 两列；侧栏可折叠 | 表单区右侧固定按钮 |
| ≥1025 | 三列；侧栏常驻 | 顶部右侧按钮 + 快捷键 |

**动作 7：微文案模板（照着套）**
- 按钮 = 动词开头：❌ `确定`／✅ `保存任务`；❌ `提交`／✅ `发布到生产`
- 错误 = 发生了什么 + 为什么 + 怎么办：
  ❌ `操作失败`（用户不知道下一步）
  ✅ `保存失败：网络断开（已重试 2 次）。请连上网络后点"重试"。`
  ✅ `邮箱格式不对：缺少 @ 符号。例：name@example.com。`
- 空状态 = 一句说明 + 一个动作：`还没有任务。点右上角"新建任务"开始。`

**动作 8：键盘与焦点顺序**
1. Tab 顺序 = 视觉从上到下、从左到右；DOM 顺序必须与视觉一致（禁止 `tabindex` 正数）。
2. Esc：关闭当前浮层并把焦点还给触发它的元素。
3. Enter：表单内不提交（提交只认按钮），搜索框内提交查询。

**动作 9：本卡产物自查（在项目根跑；输出 0 未命中、按钮档齐全、清单 8 行才算全）**
```powershell
$u = 'docs/UI.md'
$l = @(Get-Content $u -Encoding UTF8)
"UI.md 行数 $($l.Count)"
$miss = @('S1','S2','S3','S4','S5','S6','S7','S8','32','40','48','640','1024') | Where-Object { $l -notmatch $_ }
"未命中 $($miss.Count) -> $($miss -join ',')"
"按钮档行数 $(@($l | Where-Object { $_ -match '^\| (小|中|大) \|' }).Count)"
"清单未勾行数 $(@($l | Where-Object { $_ -match '^   - \[ \]' }).Count)"
```

**禁令（违反任意一条 = 本轮输出作废）：**
- 禁止只交"好看的样子"：八态缺一个 = 未完成
- 禁止用 placeholder 当表单标签，禁止把错误藏到提交之后才显示
- 禁止出现无文案的图标按钮（必须有可读标签或 aria-label）
- 禁止在 UI.md 里写"待定/后续再补"，给不出就写 `N/A（理由）`
