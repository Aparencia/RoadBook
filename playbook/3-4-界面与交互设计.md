**动作 2：八态矩阵（每个列表／表单／详情都要过一遍；每行必须带 S1–S8 ID，模板 `docs/UI.md` 已带；ID 只用于自检引用）**

| ID | 状态 | 判据（什么时候是它） | 画法 |
| :-- | :-- | :-- | :-- |
| S1 | 空态 | 请求成功但 0 条数据 | 三件套缺一不可：小图标或插画 + 一句为什么空 + 一个修复动作；禁止只显示无上下文的"暂无数据" |
| S2 | 加载态 | 请求发出到返回 | 可预测形状（列表／卡片／表格）用骨架屏，禁止圆形 spinner；局部改按钮内 spinner 并替换标签（不并排添加）；超 1 s 才显示 |
| S3 | 错误态 | 请求失败或校验不过 | 写清发生了什么 + 为什么 + 怎么办，给重试按钮 |
| S4 | 成功态 | 写操作返回成功 | 就地反馈（Toast 3 s 或行内勾）；不弹全屏 |
| S5 | 无权限 | 返回 401/403 | 说明缺哪个权限、找谁开；不给空白页 |
| S6 | 离线 | `navigator.onLine` 为 false | 顶部条提示 + 禁用写操作 + 保留只读缓存 |
| S7 | 超长文本 | 单字段超 200 字符或含无空格长串 | 截断 2 行 + 悬浮显示全文；长串强制换行 |
| S8 | 极端数值 | 0、负数、超 1 亿、空数组 | 先定义显示口径（如 ≥1 万显示 1.2 万）；禁止超框 |

❌ 反例：只画了有数据的样子，或八态只写一句"已设计／已检查"，空表和 500 错误到上线才第一次见
✅ 正例：八态各写清怎么手动造出来（3 步操作，例：F12 → Application → Local Storage → 把 drink.water.v1 改成 999 → 刷新），并贴复现结果（真实命令输出或文件路径）；截图/录屏只在 L 档当可选补充证据

**动作 5：表单规则（五条写死）**
1. 标签在上（不用 placeholder 当标签）；2. 必填加 `*` 并在表单顶部注明 `* 为必填`；3. 校验时机 = 失焦 + 提交（输入中不报错）；4. 错误位置 = 字段下方，紧贴输入框；5. 错误文案禁止只写"输入有误"。

| 断点 | 布局 | 主操作 |
| :-- | :-- | :-- |

**动作 7：微文案模板（照着套）**
- 按钮 = 动词开头：❌ `确定`／✅ `保存任务`；❌ `提交`／✅ `发布到生产`
- 错误 = 发生了什么 + 为什么 + 怎么办：
  ❌ `操作失败`（用户不知道下一步）
  ✅ `保存失败：网络断开（已重试 2 次）。请连上网络后点"重试"。`
  ✅ `邮箱格式不对：缺少 @ 符号。例：name@example.com。`
- 空状态 = 一句说明 + 一个动作：`还没有任务。点右上角"新建任务"开始。`

**动作 8：键盘与焦点顺序**
1. Tab 顺序 = 视觉从上到下、从左到右；DOM 顺序必须与视觉一致（禁止 `tabindex` 正数）。
2. Esc：关闭当前浮层并把焦点还给触发它的元素。
3. Enter：表单内不提交（提交只认按钮），搜索框内提交查询。

**动作 9：交互五态与焦点环（每个可交互元素逐个对）**
1. 五态齐备：default／hover／`:focus-visible`／`:active`／disabled，缺一个 = 不合格；禁用态三通道同时给：整块透明度 0.4–0.5 + `cursor: not-allowed` + 原生 `disabled`（或 `aria-disabled="true"`）；禁止用禁用态表示加载中。
2. 焦点环规格写死：`outline: 2px solid var(--color-focus); outline-offset: 2px;`；静止态预留 `outline: 2px solid transparent` 防几何跳变；焦点必须瞬时出现（0 ms，禁止渐显）；禁止用 `border` 或 `box-shadow` 冒充焦点环。
3. 状态切换不得改变 `border-width`／`padding`／`height`，只允许 background-color、outline、box-shadow、border-color 变化。
4. hover 规则必须包在 `@media (hover: hover)` 内，且每个 hover 效果都要有 focus 等价物（禁止 hover-only 才可见的信息）。
5. 触控目标三口径：Web 指针目标 ≥24×24 CSS px（WCAG 2.2 AA）；触控目标 ≥44×44 pt（iOS）／48×48 dp（Android）；相邻触控目标间距 ≥8 px。
6. 输入框高度必须等于同表单相邻按钮高度（同取 32／40／48 三档之一），禁止 38 px 输入配 44 px 按钮。

❌ 反例：`overflow: hidden` 的卡片里写 `:focus { box-shadow: 0 0 0 3px ... }` → 焦点环被裁掉一半，键盘用户看不见自己在哪
✅ 正例：`:focus-visible { outline: 2px solid var(--color-focus); outline-offset: 2px }`，且焦点色对元素背景与页面底色都 ≥3:1

**动作 10：页面与布局纪律（先定版面，再画组件）**
1. 布局族限额：主页面 ≥8 个区块时至少出现 4 种不同布局族，同一布局族全页最多出现一次；连续「左图右文／左文右图」最多 2 节，第 3 节即判失败。
2. hero 上限：桌面顶部内边距 ≤6 rem；文本元素 ≤4 个（eyebrow 或品牌条二选一、标题、副文、CTA）；标题 ≤2 行、副文 ≤20 词且 ≤4 行、CTA 不滚动即可见；CTA 下方的小标语、信任条、价格预告移到下一节。
3. 居中必须有理由：整页居中元素最多 2 个，其余元素打破轴线（50/50 分屏、左文右图、不对称留白）；禁止默认整页居中堆叠。
4. 单页单主题：暗色页不夹浅色区块（反之亦然），除非 brief 明确要求一次滚动主题切换；单主 CTA：一屏最多 1 个 primary，同意图的 CTA 全页只能有一个文案。
5. 禁用默认三列等宽「图标在上、标题在下」功能卡；bento 网格单元数必须等于内容条数，且至少 2–3 格有真实视觉差异（图、品牌色底、纹样）。
6. eyebrow（标题上方小号大写宽字距标签）每 3 节最多 1 个；节标题禁止「左大标题 + 右小说明」分栏，标题与说明必须纵向堆叠（说明 ≤65ch）。
7. 禁「AI 导航／页脚指纹」：wordmark 左 + 4–5 内联链接 + 右侧按钮 + 1 px 发丝底线；页脚四列链接 + 社交图标 + 版权 + 中性灰底 —— 除非页面目的地确实只有 2 个，或是真正的 docs 根。

❌ 反例：首页三节都是左图右文 + 三列等宽卡片 + 整页居中 hero
✅ 正例：同一页面出现分屏 hero、通栏大图、错落两列、时间线四种布局族；居中只用于 hero 标题

**动作 11：响应式与防溢出（每个页面在四个宽度各看一遍）**
1. 四宽度必过：320／375／414／768 CSS px，任一出现横向滚动 = 本卡未完成（四宽度是验证宽度，断点仍按动作 6 的三档）。
2. 移动优先：基础样式面向最小视口，用 `min-width` 逐级加上去；断点取内容断裂处，不按设备型号定。
3. 连续变化用 `clamp()`，离散变化用媒体查询：`h1 { font-size: clamp(2.5rem, 4vw + 1rem, 4.5rem) }`。
4. 防撑破：含图网格轨道写 `minmax(0, 1fr)`（裸 `1fr` 的最小值是 auto，会被大图撑破）；文本子项加 `overflow-wrap: anywhere; min-width: 0`（禁止对正文整体 `word-break: break-all`）。
5. 全高区块用 `min-height: 100dvh`（禁止 `height: 100vh`）；页面级写 `html, body { overflow-x: clip }`（用 `clip` 不用 `hidden`，`clip` 不破坏 sticky／fixed）。
6. 小于 768 px 时每节必须显式声明单列回退（宽度 100%、左右内边距 1 rem），不许依赖框架默认行为。
7. 可点击文字永不换行：按钮、导航、面包屑、标签页在 320–1920 px 全区间单行；修法是缩短文案，其次 `white-space: nowrap` + 父容器可收缩。
8. 通栏元素用 `env(safe-area-inset-*)`；弹窗／抽屉内写 `overscroll-behavior: contain`。

❌ 反例：桌面三列网格在 375 px 撑出横向滚动条；CTA 文案挤成两行
✅ 正例：`grid-template-columns: repeat(auto-fit, minmax(0, 1fr))` + `@media (max-width: 767px) { .grid { grid-template-columns: 1fr } }`

**动作 12：反 AI 味与文案格式（交付前跑下面的命令，命中 0 才算过）**
1. 禁止编造量化声明：`10x faster`、`trusted by 50,000+ teams`、`99.9% uptime`、`+47% conversion` 一律不许出现；数字不得单独当标题，必须配一行说明其含义的文字。
2. 禁止占位人名与创业陈词：Jane Doe／John Smith／Acme／Nexus／Seamless／Unleash／Elevate／Next-Gen。
3. 全页长破折号数必须为 0，含标题、正文、按钮、alt、字幕；需要停顿用逗号、冒号或括号。
4. 禁止假 UI chrome：手搓假浏览器栏、假手机框、假终端／IDE 框一律不许；要展示产品就用真实截图（`<figure>` + `<picture>`）或去掉边框。
5. 禁止纯文字充当极简：极简页面也要 2–3 张真实图片（主视觉 + 产品／场景 + 辅图）；logo 墙只放真实 SVG logo，不加行业标签。
6. 文案格式：用真弯引号；省略号用一个字符（不是三个点）；数字与单位之间用不换行空格；数字列与计时加 `font-variant-numeric: tabular-nums`；短的多行标题加 `text-wrap: balance`。
7. 禁止无因装饰：漂浮光标、扫描线、渐变 blob、无语义圆点、版本号页脚、滚动提示、区块编号 eyebrow。

❌ 反例：`Trusted by 50,000+ teams` + 假 MacBook 边框 + 三个点结尾的加载文案
✅ 正例：`本地保存，无需联网。` + 真实产品截图 + `保存中…`

```powershell
$ext = @('.html', '.css', '.tsx', '.jsx', '.vue')
$files = @(Get-ChildItem -Recurse -File | Where-Object { $ext -contains $_.Extension -and $_.FullName -notmatch 'node_modules' })
$pat = @([char]0x2014, 'height:\s*100vh', 'outline:\s*none', 'word-break:\s*break-all')
$hit = @()
foreach ($f in $files) {
  $t = Get-Content $f.FullName -Raw -Encoding UTF8
  foreach ($p in $pat) { if ($t -match $p) { $hit += "$($f.Name) :: $p" } }
}
"AI 味与防溢出命中 $($hit.Count)（要求 0）"
$hit
```

**动作 13：本卡产物自查（在项目根跑；非开发者只看退出码：exit 1 = 本卡未完成。0 未命中、按钮三档齐、清单全勾、行数 ≤120 才算过）**
变量名一律 ASCII：Windows PowerShell 5.1 读无 BOM 的 .ps1 时中文变量名会报『字符串缺少终止符』；脚本必须存成 UTF-8 带 BOM。
```powershell
$u = 'docs/UI.md'
$l = @(Get-Content $u -Encoding UTF8)
$text = $l -join "`n"
"UI.md 行数 $($l.Count)（要求 ≤120）"
$need = @('S1','S2','S3','S4','S5','S6','S7','S8','32','40','48','640','1024','焦点环','320','768','dvh','tabular-nums')
$miss = @(); foreach ($t in $need) { if ($text -notmatch [regex]::Escape($t)) { $miss += $t } }
"八态与断点未命中 $($miss.Count) -> $($miss -join ',')（要求 0）"
$btn = @($l | Where-Object { $_ -match '^\| (小|中|大|sm|md|lg|Small|Medium|Large) \|' }).Count
$todo = @($l | Where-Object { $_ -match '^   - \[ \]' }).Count
"按钮三档行数 $btn（要求 3）；清单未勾行数 $todo（要求 0）"
if ($l.Count -gt 120 -or $miss.Count -gt 0 -or $btn -ne 3 -or $todo -gt 0) { Write-Host '[FAIL] 本卡自查未过'; exit 1 } else { Write-Host '[OK] 本卡自查通过' }
```

**禁令（违反任意一条 = 本轮输出作废）：**
- 禁止只交"好看的样子"：八态缺一个 = 未完成
- 禁止用 placeholder 当表单标签，禁止把错误藏到提交之后才显示
- 禁止出现无文案的图标按钮（必须有可读标签或 aria-label）
- 禁止在 UI.md 里写"待定/后续再补"，给不出就写 `N/A（理由）`
