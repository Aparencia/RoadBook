**动作 2：清点（先列全，再挑重点）**

```powershell
Get-ChildItem docs/decisions -Filter '*.md' -File | Sort-Object Name | Select-Object Name, LastWriteTime, @{ n = '复核日'; e = { if ((Get-Content $_.FullName -Raw -Encoding UTF8) -match '复核[:：]\s*(\d{4}-\d{2}-\d{2})') { $Matches[1] } else { '未登记' } } } | Format-Table -AutoSize
```
Expected：直接渲染出一张 `Name / LastWriteTime / 复核日` 三列表（本仓实测 4 份决策文档、4 行全 `未登记`——`docs/decisions/` 里目前没有一份写了 `复核：<日期>` 行）；`复核日` 读的是正文里的 `复核：YYYY-MM-DD`，没有就写 `未登记`。⚠️ 把这条围栏**赋给变量**会把格式对象吞掉：实测 `$x = … | Format-Table -AutoSize` 得到 8 个 `FormatStartData/FormatEntryData` 对象、屏幕上什么都不打 ⇒ 要落文本用 `| Out-String`。⚠️ 列宽按**字符数**算、CJK 是双宽 ⇒ 中文名那一列会错位（读数不受影响）。⚠️ `docs/decisions` 不存在时打 `Get-ChildItem : 找不到路径…`（走 stderr、非终止），`$LASTEXITCODE` 仍为空 ⇒ 这条围栏给不出退出码信号。

清点表三列：**决策卡 / 状态（已复核｜本次复核｜跳过+原因）/ 到期日**。跳过必须写原因——"没时间"不算原因，要写清为什么这条现在翻它没意义。

| :-- | :-- | :-- | :-- |
| DEC-003 选本地文件存储 | "只有一个写入者，不做并发" | 出现第二个写入者（后台任务）——见提交 `<哈希>` | **侥幸成立** |

要求：
- **"当初的假设"必须是决策卡里的原句**，加引号；找不到原句就在本表里写"当初未写理由"，并把"补写理由"列为本轮改动
- **"今天的实际"必须有可核对的东西**：命令输出、提交哈希、文件路径、实测数字。**不许写"感觉还行"**

**动作 4：四值判定与"侥幸成立"专项（本卡最值钱的一段）**

| 结论 | 判据 | 处置 |
| :-- | :-- | :-- |
| **成立** | 假设仍成立，且理由站得住 | 回填下一轮复核日期，不动 |
| **侥幸成立** | 结论对，但**理由已被证伪或从未成立** | 必写"理由错在哪" + 给一条能防住同类错误的改动 |
| 不成立但没代价 | 假设已破，但还没造成损失 | 三选一：改正 / 登记技术债 / 接受（理由） |
| 不成立且已付代价 | 假设已破且有实际损失 | 三选一 + 补一条"当初哪个信号本可以更早看到" |

**"侥幸成立"专项三问**（每条都要答全）：
1. 结论为什么看起来是对的？（哪一步恰好抵消了错误理由）
2. 如果再来一次、条件稍变，会怎样？（写出那个"稍变"是什么）
3. 有没有一条**机器能判**的检查能挡住同类推理？（有就写成断言，没有就写成清单条目）

**动作 6：回填复核日期**

**动作 7：决策复盘自查（在项目根跑；非开发者只看退出码：exit 1 = 本卡未完成）** 变量名一律 ASCII：Windows PowerShell 5.1 读无 BOM 的 .ps1 时中文变量名会报『字符串缺少终止符』；脚本必须存成 UTF-8 带 BOM。
```powershell
$f = @(Get-ChildItem docs/decisions -Filter 'REVIEW_*.md' -File -ErrorAction SilentlyContinue | Sort-Object LastWriteTime -Descending); if ($f.Count -eq 0) { Write-Host '[FAIL] 找不到 REVIEW_<日期>.md'; exit 1 }; $l = @(Get-Content $f[0].FullName -Encoding UTF8); $txt = $l -join "`n"; $four = @('成立','侥幸成立','不成立' ) | Where-Object { $txt -match $_ }; $rows = @($l | Where-Object { $_ -match '^\|' -and $_ -match 'DEC-|决策' }).Count; $land = @($l | Where-Object { $_ -match 'docs/lessons/|AGENTS\.md|TECH_DEBT\.md|STATE\.md' }).Count; $lucky = @($l | Where-Object { $_ -match '侥幸成立' }).Count; "复核记录 $($f[0].Name) 行数 $($l.Count)（要求 ≤120）"; "四值命中 $($four.Count)/3；决策行 $rows（要求 ≥1）；落点行 $land（要求 ≥1）；侥幸成立命中 $lucky（要求 ≥1）"; if ($l.Count -gt 120 -or $four.Count -lt 3 -or $rows -lt 1 -or $land -lt 1 -or $lucky -lt 1) { Write-Host '[FAIL] 本卡自查未过'; exit 1 } else { Write-Host '[OK] 本卡自查通过' }
```
Expected：没有 `REVIEW_*.md` → 只打 `[FAIL] 找不到 REVIEW_<日期>.md`、退出码 **1**。有 REVIEW 时先打三行读数（`复核记录 <文件名> 行数 N（要求 <= 120）` / `四值命中 n/3；决策行 n（要求 >= 1）；落点行 n（要求 >= 1）；侥幸成立命中 n（要求 >= 1）`）：任一不满足再打 `[FAIL] 本卡自查未过`、退出码 1；全满足打 `[OK] 本卡自查通过`、退出码 0。⚠️ 三值**不互斥**：`成立` 是 `侥幸成立` 的子串——实测只写「侥幸成立」+「不成立」两行就 3/3，"四值命中"这一格实际只挑得出「不成立」出现过没有。⚠️ `$f[0]` 取 LastWriteTime **最新**那份，目录里有多份时静默只查一份。本卡读数取自**子进程**（我按 `-File <脚本>` 跑再读 `$LASTEXITCODE`）；把 `exit 1` 直接贴进交互式控制台会连会话一起关掉。
