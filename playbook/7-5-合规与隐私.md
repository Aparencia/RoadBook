# 卡 7-5 · 合规与隐私（收个人数据 / 对外发布必走）
> 触发：收集个人信息 / 上线公开服务 / 接第三方 SDK ｜ 产物：docs/PRIVACY.md + 根 LICENSE ｜ 下一张：4-1 分批编码（要改代码时）/ 5-1 归档（纯治理）
> 过程域：RISK, QA

---

## ① 开工确认

1. **人话复述与落点**：本项目的用户数据都有哪些、要对外发布什么；产物 = `docs/PRIVACY.md` + 根 `LICENSE`；下一张卡 = 4-1 分批编码（本卡产生代码改动时）。
2. **假设清单**：逐条写"我假设 X；若错则 Y 失效"（例："全项目没有收款功能，所以不涉及支付数据"），每条注明验证方式；能从 docs/registry/DATA_DICT.md 或源码查到的不许写进假设。
3. **澄清问题（≤5 个，能删则删）**：默认四问——收集哪些个人字段（邮箱/手机号/地址/证件/位置）？数据给哪些第三方看（SDK、邮件服务、统计）？服务对哪些地区开放（决定适用哪套法规口径）？删除请求的时限承诺几天？一个都没有就写"无"。
4. **判定预告**：会先做数据地图，再按 D1~D4 分级；若本项目确实不涉及个人数据且不对外发布，判定 `N/A（理由）` 并写明理由。
5. **引用本卡检查清单原文**（逐字粘贴 §② 的"合规五查"）：
   - [ ] 数据地图五列齐全（收集什么/为什么收/存在哪/保留多久/给谁看），每格都有内容或 `N/A（理由）`
   - [ ] 每个个人字段标了敏感度 D1~D4，D3/D4 有加密或脱敏的落点文件与行
   - [ ] 访问/更正/删除/撤回同意四条权利各有可复制的操作路径（具体页面或命令）
   - [ ] 第三方依赖许可证与根 LICENSE 的兼容性逐条核对完，结果写进报告
   - [ ] 密钥与日志脱敏核对完成（真实密钥零出现，D3/D4 字段不外泄）
6. **边界声明**：合规口径由用户裁决；账号密钥与真实数据的删除、导出由人执行，agent 只出草案与证据。

## ② 执行

**本卡检查清单（合规五查，逐条勾选）：**
- [ ] 数据地图五列齐全（收集什么/为什么收/存在哪/保留多久/给谁看），每格都有内容或 `N/A（理由）`
- [ ] 每个个人字段标了敏感度 D1~D4，D3/D4 有加密或脱敏的落点文件与行
- [ ] 访问/更正/删除/撤回同意四条权利各有可复制的操作路径（具体页面或命令）
- [ ] 第三方依赖许可证与根 LICENSE 的兼容性逐条核对完，结果写进报告
- [ ] 密钥与日志脱敏核对完成（真实密钥零出现，D3/D4 字段不外泄）

**动作 1：数据地图（五列，缺一列 = 未完成）**
逐字段填：收集什么 / 为什么收（用途）/ 存在哪（表或文件）/ 保留多久 / 给谁看（哪些第三方、内部谁能看）。
```powershell
$kw = 'email'        # 逐个字段换关键词：email / phone / address / location
Get-ChildItem -Path src -Recurse -File | Select-String -Pattern $kw | Select-Object Path, LineNumber
Select-String -Path docs/registry/DATA_DICT.md -Pattern $kw | Select-Object LineNumber, Line
```
（注：本机 PowerShell 5.1 里 `-Recurse` 不是 `Select-String` 的合法形参，只有上面的管道式递归可跑）
- ❌ 反例："收集邮箱用于通知"（没说存哪、存多久、谁能看）
- ✅ 正例："邮箱｜注册与订单通知｜users 表 email 列｜账号注销后 30 天｜仅后端服务与邮件服务商 X"
- 表格里出现真实用户数据 = 违规，只写字段名与类型。

**动作 2：敏感度分级 D1~D4 与处置**
- D1 公开：产品名、公开文档 → 无额外处置
- D2 内部：用户 ID、订单号 → 访问控制（不给外部）
- D3 个人：邮箱、手机号、地址、设备标识 → 传输与静态加密 + 界面默认掩码 + 日志禁写
- D4 敏感：密码哈希、支付信息、证件号、精确位置、健康数据 → 加密 + 强访问控制 + 访问留痕 + 最小化（能不收就不收）
```powershell
Select-String -Path docs/registry/DATA_DICT.md -Pattern 'D3|D4' | Select-Object LineNumber, Line
Get-ChildItem -Path src -Recurse -File | Select-String -Pattern 'phone|id_card|latitude|password' | Select-Object Path, LineNumber
```
- ❌ 反例："手机号算普通信息，不用管"
- ✅ 正例："手机号 = D3：入库前加密，界面只显示 138****1234，日志禁止打印原值"
- D4 字段未加密 = 红灯：停下问用户，禁止对外发布。

**动作 3：用户权利路径（四条，各写到可操作）**

| 权利 | 入口 | 谁执行 | 时限 |
| :-- | :-- | :-- | :-- |
| 访问 | 账号设置 →"我的数据"页 | 用户自助 | 即时 |
| 更正 | 账号设置 → 资料编辑 | 用户自助 | 即时 |
| 删除 | 提交删除请求（页面/邮箱/工单） | 人执行（不可委托） | ≤30 天 |
| 撤回同意 | 设置 →"隐私与同意"页取消勾选（或回退订邮件） | 用户自助 | 即时 |

- "入口"必须写到具体页面或命令，写"联系管理员"不合格。
- 删除涉及真实数据：agent 只起草路径与命令草案，执行由人完成并留痕。

**动作 4：第三方依赖许可证核对**
```powershell
npm ls --depth=0            # Node 项目；Python 项目换成 pip list
```
- 把 `name@version` → license 逐条抄进 `docs/PRIVACY.md` 的"依赖许可清单"；再与根 `LICENSE` 比对兼容性。
- 兼容：MIT / Apache-2.0 / BSD / ISC 可与 MIT 类许可共存；GPL / AGPL / SSPL 有传染性或使用限制 → 停下问用户，并在 docs/TECH_DEBT.md 登记替换候选。
- ❌ 反例："依赖挺多的，应该都是 MIT"
- ✅ 正例："逐个列出 37 个依赖的 license；发现 xxx@2.1.0 是 AGPL-3.0 → 停下问用户，登记替换候选 TD-012"

**动作 5：外部来源的合规核对（第三方技能 / 插件 / MCP server / 外部 CLI）**
- 本卡只判**合规面**（许可证义务、数据流向、归属背书）；**准入面**（来源可信度、权限边界、可撤销性）不在本卡判——本卡给合规结论，准入那一关单独给准入结论，两者互不替代。
- ① 许可证类型与义务：逐项记下许可证名（MIT / Apache-2.0 / GPL-3.0 / 商业许可 / 无许可证），并回答三问：是否要求保留 NOTICE 或版权声明、修改过的文件是否要标注「已修改」、是否允许商用。❌ 只看"能跑通"就放行｜✅ 把许可证名与三问答案写进 ③ 回执；无许可证或禁止商用 = 红。
- ② 数据流向：它会把项目数据发到哪里？❌ 默认"应该不发"｜✅ 查它的配置与文档，列出发出的字段、目的地（域名/厂商）、是否出境、是否走第三方 SDK 条款；发到不可控的外部服务 = 红。
- ③ 归属与背书：❌ 在文档里写"官方推荐""官方合作"｜✅ 只写"使用了某开源项目"，不得暗示本项目或用户与对方存在官方背书关系。

**动作 6：隐私政策要点（面向用户的人话版）**
写进 `docs/PRIVACY.md` 的"给用户看的一页"节，六句：收什么 / 为什么收 / 存多久 / 给谁 / 怎么删 / 怎么联系。
- ❌ 反例："基于合法利益处理个人数据"（用户看不懂）
- ✅ 正例："我们用你的邮箱给你发订单通知；不想收可以在设置里关掉。"

**动作 7：密钥与日志脱敏核对**
```powershell
Get-ChildItem -Path src -Recurse -File | Select-String -Pattern 'api[_-]?key|secret|password\s*='
Get-ChildItem -Path src -Recurse -File | Select-String -Pattern 'console\.log|logger|print' | Select-String -Pattern 'email|phone|token|password'
```
- 第一条命中真实密钥 = 红线：停下，让人作废并轮换该密钥（git 历史永远可读），改完复跑取零命中。
- 第二条命中 D3/D4 字段 = 改日志（打印脱敏值或去掉），改完复跑取零命中。

**动作 8：不适用判定**
项目不收个人数据、不对外发布、不接第三方 SDK → 在 `docs/PRIVACY.md` 写 `N/A（理由：…）` 后结束本卡。禁止留空文件，也禁止跳过判定（"没做"和"判定不适用"是两回事）。

**禁令（违反任意一条 = 本轮输出作废）：**
- 禁止 agent 执行真实数据的删除或导出（不可委托：只能人执行）
- 禁止把真实密钥、真实个人信息写进报告、示例或提交信息
- 禁止空格留白：每格写内容或 `N/A（理由）`
- 禁止未核对许可证就对外发布
- 触碰认证/支付/删数据 → 停下升级档位（L 档并走 3-2 威胁建模）
