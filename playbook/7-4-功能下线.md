> 触发：功能寿终、用户说"下线/删掉 X" ｜ 产物：删除提交 + 下线记录（registry 行 / CHANGELOG 废弃行 / `docs/versions/<版本>.md` 下线条目） ｜ 下一张：5-1 归档
> 过程域：OPS

## ① 开工确认

1. **下线对象复述**：下线哪个功能/接口/页面（从用户原话引用），涉及哪些用户可见的东西。
2. **假设清单**：你替用户做的 3~5 条默认假设（例："该功能无外部调用方""数据可导出后再删"），每条注明验证方式。
3. **澄清问题（≤5 个，能省则省）**：必问数据处置——相关数据是保留（导出后删）、只隐藏入口、还是彻底删？另两问——通告期多长？替代方案是什么？代码与 RUNBOOK 里查得到的禁止问人。
4. **影响面预告**：将用 `Select-String` 核对"被谁调用"，先回执清单再动手。
5. **引用检查清单原文**（逐字粘贴本卡 §② 的"下线四步"）。
6. 并声明：产物落点 = 删除提交 + 下线记录（registry 行 / CHANGELOG 废弃行 / `docs/versions/<版本>.md` 下线条目）；下一张卡是 5-1（归档）。

## ② 执行

**下线四步：**

**第 1 步 影响面盘点（先看后删）**
```powershell
$target = 'GET /api/export'      # 接口路径/组件名/表名，逐个试
Get-ChildItem -Path src -Recurse -File | Select-String -Pattern $target | Select-Object Path, LineNumber, Line
```
Expected：命中时打一张 `Path / LineNumber / Line` 三列表（`Path` 是**绝对路径**；本机沙箱实测一行 = `…/src/api/export.ts  2  return 'GET /api/export'`）；**零命中时一个字符都不打**，`src` 目录根本不存在时同样零输出（`-Recurse -File` 连「找不到路径…」都不报、`$Error.Count` 实测 0，去掉 `-Recurse` 才报），而 `$?` 仍是 `True`、`$LASTEXITCODE` 保留调用前的残留值（实测塞 77 进去原样留着）⇒ **空输出不等于"干净"**：判据要写成"先 `Test-Path src` 为真、再看 `@(…).Count` = 0"，两步都留输出。
列出：接口被哪些前端调用 / 组件被哪些页面引用 / 表被哪些代码读写。有遗漏 = 删除后炸别处。
❌ 反例：`grep -rn "<接口路径/组件名/表名>" src`（bash 专用命令 + 占位符，Windows 上跑不动，漏检就白删）
✅ 正例：上面那条 `Get-ChildItem -Path src -Recurse -File | Select-String -Pattern $target`（PowerShell 5.1 可跑，输出 Path/LineNumber/Line）
   （注：本机 PowerShell 5.1 里 `-Recurse` 不是 `Select-String` 的合法形参，只有上面的管道式递归可跑）
❌ 反例：只删了页面文件，接口还挂着 → 变成没人用的裸接口（安全面）
✅ 正例：前端入口、后端接口、表、错误码、文档五行一起列，逐项划掉

**第 2 步 先通告后删除**（有真实用户才需要；记录到 docs/RUNBOOK.md §5 或 `docs/versions/<版本>.md` 的下线条目）
- 给出下线通告文案草案（什么时候下线/替代方案是什么/数据怎么领回）。
- 通告期结束前不动手。

**第 3 步 数据处置（按用户拍板执行）**
- 保留导出：给导出命令草案，**人执行**导出并确认文件存在后才进删除。
- 彻底删表/删列：属于破坏性变更，agent 只生成迁移草案，**人执行 SQL**（宪法不可委托）。
- 只隐藏入口（不删数据）：关掉入口开关 + 在 `docs/registry/COMPONENTS.md` 对应行标注"已隐藏（日期）" + 留 30 天观察期（起止与到期处理写进 `docs/versions/<版本>.md` 下线条目；到期仍零调用才删代码）。

**第 4 步 删除与同步**（提交动作放 §④，先回写状态再提交；本步只把改动准备好）
- 删代码 + 同步清理：`docs/registry/APIS.md`（删行或标注 503 负向契约）/ `COMPONENTS.md` / `DATA_DICT.md` 对应行
- 根 `CHANGELOG.md` "废弃"节追加一行（含替代方案与数据领取方式）
- `docs/versions/<版本>.md` "下线"节追加一行（功能名 / 下线日期 / 替代方案 / 数据领取方式）
- 删不掉的部分（有外部引用/通告期未满）→ 登记 `STATE.md` 并行态登记簿或 `docs/TECH_DEBT.md`

**禁令：**
- 禁止"先删再说"——影响面没核对完不许动第一行代码
- 禁止替用户决定数据处置方式
- 禁止删除共用组件/工具函数（先确认无他人引用）

## ④ 状态回写

**顺序铁律：先回写状态 → 再提交 → 再复跑 check.ps1 取 0。**

更新 STATE.md：`当前任务` 清空；`下一步` = 5-1 归档；`未决问题` = 遗留事项（如通告期未结束）。

然后提交与复跑：
```powershell
$slug = 'export-v1'; $feature = '导出 v1 接口'; $ver = 'v0.4.0'
git add STATE.md CHANGELOG.md docs/versions/$ver.md docs/registry/APIS.md docs/registry/COMPONENTS.md docs/registry/DATA_DICT.md src/api/export.py
git commit -m "7-4 feat($slug): remove $feature"
powershell -NoProfile -File check.ps1
```
Expected：这条 `git add` 的清单里每个路径都必须真实存在（`docs/versions/$ver.md` 由本卡第 2/3 步产出；被删的实现文件删掉后仍要 `git add` 它才记进本次提交）：任一路径不存在 → `fatal: pathspec '…' did not match any files` + **退出码 128**、`git commit` 不执行（registry 与 CHANGELOG 也就没进这次提交 = 幽灵行）。`git commit` 成功打 `[main <短哈希>] 7-4 feat(export-v1): remove 导出 v1 接口` + ` N files changed, M deletions(-)`、退出码 0；`check.ps1` 末行 `全部通过（退出码 0）：完成声明成立。`
（禁止 `git add -A` / `git add .`；代码删除、registry 行、CHANGELOG 废弃行、versions 下线条目与 STATE.md 必须同一次提交。）
❌ 反例：只提交代码删除，registry 与 CHANGELOG 留到"下次归档再补"（文档指向已删接口 = 幽灵行）
✅ 正例：删除、registry 三行、CHANGELOG 废弃行、versions 下线条目、STATE.md 一次提交，回执贴提交哈希
