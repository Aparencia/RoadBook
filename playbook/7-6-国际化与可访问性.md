3. **澄清问题（≤5 个，能删则删）**：默认三问——支持哪些语言与地区（含日期、货币、时区口径）？无障碍达标线是不是 WCAG 2.1 AA（正文对比度 ≥4.5:1、触摸目标 ≥44px）？时间有限时先做文案外置还是先修可访问性？一个都没有就写"无"。
4. **引用本卡检查清单原文**（逐字粘贴 §② 的"i18n/a11y 四查"）：
   - [ ] 文案外置：src 下硬编码界面字符串扫描零命中（白名单行已登记理由）

   - [ ] 受影响界面的「影响面」列已同批回写可访问性标注
5. **边界声明**：语言优先级与达标线由用户裁决；agent 只出清单、实测证据与改动草案。

**动作 1：文案外置（禁止界面硬编码字符串）**
```powershell
Select-String -Path src -Recurse -Pattern '[\u4e00-\u9fa5]' | Where-Object { $_.Path -notmatch 'locales|i18n' } | Select-Object Path, LineNumber
```
- 命中行逐条处理：搬进语言包（`locales/zh-CN.json` 等），组件里改成取键；确实不该外置的（正则、日志）写进白名单并注明理由。
- ❌ 反例：`<button>保存</button>`（界面字符串写死在组件里）
- ✅ 正例：`<button>{{ t('common.save') }}</button>` + `locales/zh-CN.json` 里 `"common.save": "保存"`

**动作 2：语言与区域表（五列，写进 docs/I18N.md）**

| 项 | 中文（zh-CN） | 第二语言示例（en-US） | 口径 |
| :-- | :-- | :-- | :-- |
| 界面语言 | 中文 | English | 默认跟随系统，可手动切换 |
| 日期 | 2026-10-03 | Oct 3, 2026 | 一律用语言包格式化，禁止手拼 |
| 数字 | 1,234.56 | 1,234.56 | 千分位与小数分隔符按地区，不写死 |
| 货币 | ¥1,234.56 | $1,234.56 | 金额必须带币种代码（CNY/USD），不靠符号猜 |
| 时区 | UTC+8 展示 | 用户时区展示 | 存储一律 UTC，展示时转换 |

**动作 3：三个经典陷阱（每个给 ❌✅）**
1. 复数：
   ❌ `count + ' items'`（英文会出现 "1 items"）
   ✅ `t('items', { count })` + 语言包按 `one/other` 分支
2. 时区：
   ❌ 直存本地时间（`DateTime.Now` / `new Date()`），换个时区看就错一天
   ✅ 存储 UTC，展示时按用户时区转换；跨天统计写明以 UTC 为口径
3. 字符串拼接：
   ❌ `'删除 ' + name + ' 吗？'`（语序因语言而异，翻译必错）
   ✅ 整句模板 `t('confirm.delete', { name })`

**动作 4：可访问性七条（每条给验证方式）**

| 项 | 判据 | 验证方式 |
| :-- | :-- | :-- |
| 键盘可达 | Tab 能到所有可交互元素，焦点不丢 | 只用键盘走完主路径（Tab / Shift+Tab / Enter / Esc），记录卡住的位置 |
| 对比度 | 正文 ≥4.5:1，大字 ≥3:1 | 浏览器 F12 取色器核对前景与背景色值，或用 axe DevTools 扫描 |
| 语义标签 | 用 button/nav/main/h1~h3，不用 div 冒充 | F12 看标签名；`<div onclick` 命中即不合格 |
| 图片替代文本 | 有意义的图有 alt，装饰图 `alt=""` | `Select-String -Path src -Recurse -Pattern '<img'` 后逐行看 alt |
| 焦点可见 | 聚焦态有可见样式（outline 或边框） | `Select-String -Path src -Recurse -Pattern 'outline:\s*none'`；再用 Tab 目检焦点环 |
| 表单标签 | 每个输入有 label 或 aria-label | F12 或 axe 扫描；`<input` 逐行核对 |
| 触摸目标 | 可点区域 ≥44×44 px | F12 量元素盒子尺寸；不足则在 CSS 补 padding 或 min-height |

**动作 5：回写注册表「影响面」列的可访问性标注**
- `docs/registry/COMPONENTS.md` 的「影响面」列约定写四类标注：影响面 / 性能 / 安全与隐私 / **可访问性**（写法见该文件底部"两列怎么写"节）。
- 受影响界面逐行更新：补可访问性标注（例：`Tab 走查：全部控件可达且焦点可见`；无关写 `N/A（纯文本）`），"最近确认"填今天。
- ❌ 反例：改完界面不回写注册表（下次不知道哪些界面受影响）
- ✅ 正例：影响面列原文"首页也引用"→"首页也引用；可访问性：Tab 走查全部控件可达、焦点可见"
