# 卡 7-10 · 技术栈迁移
> 触发：换语言／框架／存储／运行时／托管平台（实现载体整体替换，允许内部行为与数据形态变化） ｜ 产物：docs/decisions/STACK_<日期>_<主题>.md + 分批切换提交（每批一个回滚点） ｜ 下一张：4-2 自检与守卫（每批）/ 5-1 归档（收尾）
> 过程域：OPS, REL

## ① 开工确认

1. **与 7-8 的分界（先判这一句，判错就地停）**：外部行为要求不变 → 7-8；换语言／框架／存储／运行时／托管平台（实现载体整体替换）→ 本卡；要改的是用户可见行为 → 回 2-1 立项，两张卡都不收。
2. **人话复述与落点**：讲清"把哪套载体换成哪套、换完用户看到的东西一模一样"；产物 = 选型结论一条（`docs/decisions/STACK_<日期>_<主题>.md`，形状 = STACK_ + 决策日期 + 主题；本次例 `docs/decisions/STACK_2026-10-05_export-service.md`）+ 分批切换提交；下一张 = 4-2 自检与守卫（每批）/ 5-1 归档（收尾）。
3. **不可委托声明**：SQL／数据迁移／切换／删数据由人执行，agent 只产出文件与命令。
4. **假设清单**：逐条"我假设 X；若错则 Y 失效"（例："旧系统的全部调用方都在仓库里查得到"），每条注明验证方式。
5. **澄清问题（≤5 个，能删则删；每个自带推荐答案）**：换到哪套？推荐 = 四维打分总分最高者（见第 1 步），你回"同意"即可 ｜ 能接受多长停机？推荐 = 0 分钟（双跑不停机）｜ 回滚窗口留多久？推荐 = 7 天（自切换提交起算）。代码与配置里查得到的禁止问人。
6. **引用本卡检查清单原文**（逐字粘贴 §② 的"迁移八步"与"验收五件"）。

## ② 执行

**合理化红旗表（开工时逐条念；出现任一条 = 停下按本卡补做）**

| 你会想 | 事实 |
| :-- | :-- |
| 新框架跑通了就算迁移完成 | 跑通只是第一步；黑盒契约与黄金样例差异为零 + 数据对账为零 + 观察窗无回归，三样齐才算完成 |
| 旧系统先别删，留着保底 | 不登记的旧系统 = 第二处真相；要么回滚窗口到期后删掉，要么登记 STATE.md 并行态登记簿（含删除条件与到期） |
| 数据对不上是时区问题，先切了再说 | 切读的唯一判据是差异为零；"先切再归因"= 拿线上做实验 |
| 迁移就是重写一遍 | 重写换的是实现、外部行为不变（走 7-8）；本卡的等价证据来自旧系统当 oracle 的黑盒契约，不来自"又写了一遍" |

**迁移八步（一步一批，缺一步不算开工）：**

**第 1 步 选型先行（用户裁决前不许动实现代码）**
四维打分，每维 1~5 分，每维的分数必须附来源链接（无来源的分数不算）：

| 维 | 问什么 | 分数来源 |
| :-- | :-- | :-- |
| 生态与维护 | 谁在维护、最近一次发版、支持到什么时候 | 官方仓库与发版说明链接 |
| 迁移成本 | 改造面多大、数据怎么搬、要停多久 | 官方迁移指南 + 第 2 步的基线读数 |
| 运行成本 | 托管费／自建机器、监控与备份怎么做 | 官方定价页链接 |
| 退出成本 | 用两年后想换走，要付什么代价 | 官方导出格式与开放标准说明 |

- 落点 `docs/decisions/STACK_<日期>_<主题>.md`：四维分数表 + 每维来源链接 + 被否方案的否决理由（每方案一行）。
- ❌ 反例："新框架比较流行"（无分数、无来源、无被否方案）｜ ✅ 正例：三个候选 17／14／9 分，被否两个各一行理由，用户回"按 17 分那个做"

**第 2 步 基线测量（没有基线不许开工）**
- 行为基线：黄金样例 3~5 组真实输入与输出，落 `out/golden/`（旧系统当前输出原样保存）。
- 数据规模：每张表行数与总记录数，落 `docs/registry/DATA_DICT.md`。
- 性能读数：同一条命令跑 3 次取中位数；命令与三条原始读数一起贴进回执。
```powershell
1..3 | ForEach-Object { Measure-Command { powershell -NoProfile -File scripts/bench.ps1 } | Select-Object -ExpandProperty TotalMilliseconds }
```
- ❌ 反例："大概几百毫秒，够快"（无命令、无三次读数、无中位数）｜ ✅ 正例：三次 812／790／803 ms，中位数 803 ms，写进选型记录

**第 3 步 安全带：把旧系统当 oracle（跨语言也要能跑）**
- 黑盒契约：对旧系统发同一批请求（≥3 条核心路径 × 正常／空／错各一次），响应原样落 `out/contract/old/`；新系统跑同一批落 `out/contract/new/`，逐字节比对。
```powershell
$r = Invoke-WebRequest 'http://127.0.0.1:3000/api/orders/42' -UseBasicParsing
$r.Content | Set-Content -Encoding UTF8 out/contract/old/orders_42.json
```
- 黄金样例与黑盒契约没全绿，不许动第一行新实现代码；"新写的单测全绿"不算安全带（自己写的测试证明不了与旧系统一致）。

**第 4 步 数据迁移四条（缺一条不许切读）**
1. 迁移前备份：按 `docs/RUNBOOK.md` 第 5 节的备份步骤做，备份文件路径贴回执。
2. up／down 脚本：down 必须精确反向，由人在本地空跑一遍并把输出贴回；agent 只给命令，不执行。
3. 双跑对账：两侧行数与关键字段校验和，差异为零才切读。
```powershell
psql -d app_old -c "select count(*), md5(string_agg(id::text || amount::text, ',' order by id)) from orders"
psql -d app_new -c "select count(*), md5(string_agg(id::text || amount::text, ',' order by id)) from orders"
```
4. 迁移文件登记：每个迁移文件路径 + 每一列的列级口径，写进 `docs/registry/DATA_DICT.md`。
- ❌ 反例：down 让框架自动生成；对账只看总数不看关键字段 ｜ ✅ 正例：人空跑 down 的输出已贴；两侧行数 12043 = 12043 且校验和一致，差异 0

**第 5 步 切换判据与回滚窗口（写死，不许临场放宽）**
- 切换判据三条全绿才切读：① 对账差异为零 ② 黑盒契约 + 黄金样例差异为零 ③ 观察窗（默认 24 小时）内无回归。
- 回滚窗口 = 自切换提交起 7 天；窗口内旧载体、旧数据、旧配置保持可切回，切回命令一行一条写进批次表（含提交哈希）。
- 切回三步写死：停新载体承接 → 配置指回旧载体（命令给全）→ 用旧数据跑一遍黄金样例确认真复现。
- ❌ 反例："有问题就切回去"（没写窗口多久、没给切回命令）｜ ✅ 正例：`回滚窗口 2026-10-05 至 2026-10-12 ｜ 切回命令见批次表第 3 行`

**第 6 步 单向门先演练（没演练过的回滚 = 没有回滚）**
单向门 = 做下去就回不来的一步（例：删旧表、改对外接口、切域名解析）。第一次执行前，在本地或预发把整套回滚跑一遍，记录命令、结果、耗时。
- ❌ 反例：单向门直接在生产上做，出问题才发现 down 脚本没跑过 ｜ ✅ 正例：演练记录一行 `命令见批次表 ｜ 结果 成功 ｜ 耗时 4 分钟`

**第 7 步 旧载体退役（全绿后才删）**
第 5 步三条全绿后，删旧实现、旧配置、旧开关；删不掉的登记 `STATE.md` 并行态登记簿（含删除条件与到期）。
```powershell
Get-ChildItem -Path src -Recurse -File | Select-String -Pattern '_old|_legacy'
```

**第 8 步 每批纪律（不守就不算一批）**
- 一批 = 一次提交 = 一个回滚点；批与批之间 `git status --short` 必须无输出。
- 一批里禁止夹带功能改动、升依赖、改配置；发现新问题 → 登记 `docs/TECH_DEBT.md`。
```powershell
$anchor = git rev-parse --short HEAD
git status --short
git diff --numstat "$anchor..HEAD"
```

**验收五件（缺一件不算完成）**
1. **行为等价**：黑盒契约与黄金样例逐组比对，差异为零，比对原文贴回执。
2. **数据对账为零**：两侧行数与关键字段校验和一致。
3. **全量 guardrail 绿**：`powershell -NoProfile -File check.ps1` 退出码 0 + 粘贴输出。
4. **旧载体退役**：搜索零残留，或全部登记并行态登记簿。
5. **依赖与结构约束回写**：`docs/ARCHITECTURE.md` 与 `docs/registry/` 三件套（COMPONENTS／DATA_DICT／APIS）按新载体更新。

**禁令（违反任意一条 = 本轮输出作废）：**
- 禁止在选型结论获用户裁决前动实现代码
- 禁止没有基线（黄金样例／数据规模／性能读数）就开工
- 禁止拿"新写的单测全绿"当行为等价证据
- 禁止对账有差异就切读
- 禁止单向门未演练就执行
- 禁止旧载体不删也不登记
