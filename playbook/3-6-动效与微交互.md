## ② 执行

**合理化红旗表（开工时逐条念；出现任一条 = 停下按本卡补做）**

| 你会想 | 事实 |
| :-- | :-- |
| 时长表照抄 hover 100／press 50 就行 | 50ms 在 60Hz 下不足 4 帧，会被读成跳变；带位移或缩放的按压要 80–120ms |
| 加了动效更好看，降级以后再说 | 没有 reduced-motion 回退的动效 = 本卡未完成；且必须用 `no-preference` 正向前置才算覆盖全 |
| `transition: all` 省事 | 会把布局属性一起过渡 → 掉帧；必须显式列出属性 |
| 用 `animationend` 里改状态最方便 | 动画被打断或 reduce 降级时事件不触发 → 状态卡死；状态正确性不许依赖动画事件 |

**动作 1：时长表（六类，按作用域取；每项 = 基准取值 + 作用域与调整；超了就是卡顿）**
- hover 100ms：只用于无位移的即时反馈（颜色、描边、阴影），带位移或抬升用 150–200ms ｜ press 50–120ms：纯颜色加深 50–100ms，带位移或缩放（`scale`）用 80–120ms ｜ enter 200–300ms：产品 UI 用本档（短于 150ms 看不出来，不作为取值），模态与抽屉 300–420ms、演示／投屏 400–600ms
- exit = 进场的 60–75%：退场必须比进场快（300ms 进 → 180–225ms 出），绝不反过来 ｜ page 200–300ms：页面转场，禁止超过 300ms ｜ skeleton 1200ms：骨架屏循环一轮，不随内容长度变化

**动作 2：四条缓动曲线（只许用这四条，别自创；每项 = 名称 + cubic-bezier + 用途）**
- standard 标准 `cubic-bezier(0.2, 0, 0, 1)`：通用位移、尺寸变化 ｜ decelerate 减速 `cubic-bezier(0, 0, 0.2, 1)`：进场（快起步、慢收尾）
- accelerate 加速 `cubic-bezier(0.4, 0, 1, 1)`：退场（慢起步、快离开）｜ emphasized 强调 `cubic-bezier(0.34, 1.56, 0.64, 1)`：成功反馈、一次性强调；一屏最多一次
禁止 `ease` 与默认 `ease-in-out`（浏览器默认值，读作未经雕琢）；`emphasized` 禁止用于状态切换（状态切换用回弹缓动 = 判失败）；焦点环不用缓动（0ms 出现）。

**动作 3：按钮动效选项（≥6 种，按场景挑一种，不要叠着用；每项 = 场景／时长／缓动／一行 CSS／禁忌）**
- B1 按下缩放（所有可点元素的基础反馈，80–120ms，standard）：`.btn:active { transform: scale(.97) }`——禁忌：缩小超过 0.95 会像塌陷 ｜ B2 悬停抬升（卡片式按钮、可点卡片，150–200ms，standard）：`.btn:hover { transform: translateY(-1px); box-shadow: var(--shadow-2) }`——禁忌：抬升超过 2px 会晃，列表行内按钮禁用
- B3 颜色阶跃（次级按钮、纯文字按钮，100ms，standard）：`.btn:hover { background: var(--color-brand-hover) }`——禁忌：主按钮按下后必须能回到原色，禁止只变不加过渡 ｜ B4 波纹扩散（移动端主按钮、触屏列表项，200ms，decelerate）：`transform: scale(0); animation: ripple 200ms cubic-bezier(0,0,0.2,1) forwards`——禁忌：桌面端禁用（鼠标没有触点），一屏最多一处
- B5 图标位移（带箭头的"下一步/提交"，150ms，standard）：`.btn:hover .icon { transform: translateX(2px) }`——禁忌：位移超过 4px 会挤出按钮，图标不能换位 ｜ B6 不动（表格行内操作、批量操作、低端机，0ms，无缓动）：`.btn { transition: none }`——禁忌：禁止用它跳过 B1 的按下反馈（按下必须有反馈）

**动作 4：微交互清单（十项，每项都要有"触发 → 表现 → 时长"）**
- 悬停（指针进入）：底色或描边变化、不加位移；声明包在 `@media (hover: hover)` 里，并有 focus 等价反馈 ｜ 100ms ｜ 按下（指针按下）：缩放 0.97 或颜色加深，纯变色 50–100ms、带位移或缩放 80–120ms ｜ 80–120ms
- 聚焦环（Tab 进入）：`outline: 2px solid var(--color-focus)` + `outline-offset: 2px`，必须可见、禁 `box-shadow` 冒充 ｜ 0ms 瞬时，不许渐显 ｜ 按钮内加载（点击后）：文案换进行时 + 按钮内 spinner、宽度锁定 ｜ 200ms 起，随请求结束
- 骨架屏（首屏请求发出）：灰色块循环扫光；可预测形状的内容用骨架屏，不用居中转圈 ｜ 1200ms/轮 ｜ Toast 进出（写操作返回）：进场减速、退场加速（退场 = 进场的 60–75%）、3–5s 后自动消失、不抢焦点（`aria-live="polite"`）｜ 进 200ms／出 150ms
- 列表增删（提交或删除成功）：新行高度从 0 展开、删除行淡出 ｜ 200ms ｜ 折叠展开（点击标题）：`grid-template-rows: 0fr → 1fr` 过渡（不动 `height`）；内容超过一屏时改为直接切换 ｜ 200ms
- 数字变化（数值更新）：只做透明度切换，禁止滚动数字 ｜ 150ms ｜ 成功打勾（保存成功）：描边画出勾，只播一次 ｜ 300ms

**动作 5：降级（晕动症与低端机；两条都要写，缺一条 = 本卡未完成）**

正向前置：动效只写在 `@media (prefers-reduced-motion: no-preference)` 里——只写 `reduce` 分支会漏掉内联样式与第三方组件里的动效。
```css
@media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation-duration: 150ms !important; animation-iteration-count: 1 !important; transition-duration: 150ms !important; scroll-behavior: auto !important; } .btn:hover, .btn:active { transform: none; } .decorative-motion, .parallax { display: none !important; } }
```
- 位移、缩放、旋转、视差全部塌缩为透明度变化；循环动画只播 1 次并停在终态（不许停在半途）
- 功能一个都不能少：进度条、spinner、骨架屏照常显示，只是更慢或静止；动效期间按钮必须仍可点
- 静态优先：能靠一张静态图说清的动效就不要加；演示/投屏类产物的入场 400–600ms、总时长 ≤8s（该档细则见动作 8）
- 验收：DevTools 里开 `Emulate CSS prefers-reduced-motion: reduce`，逐项走一遍动作 4 十项，界面不得出现空白、错位或卡死

**动作 6：性能预算（超了就是 bug，不是"稍慢"）**
- 只动 `transform` 与 `opacity`；禁止动 `width`/`height`/`top`/`left`/`margin`（会触发重排）；单次位移 ≤8px，超过 8px 改用淡入淡出
- 目标 60fps（每帧 ≤16.7ms），掉帧就砍动效、不许砍功能；单次动效 ≤300ms，循环动效只允许骨架屏一种
- 禁止 `transition: all`（会把布局属性一起过渡 → 掉帧），必须显式列出属性名；禁止预防性 `will-change`：只写在正在动画的元素上，动画结束就移除
- 滚动联动用 `IntersectionObserver`，禁止 `window.addEventListener('scroll')`；只做一次性 reveal，不随滚动重触发；不做视差
- 每页最多 3 个不同动画原语；错峰用 `animation-delay: calc(var(--i, 0) * 60ms)`，总错峰 ≤500ms（列表每项 30–50ms）
- 动效必须可中断；**状态正确性不得依赖 `animationend`/`transitionend`**（降级或中途打断时事件不触发 → 状态卡死）
- 自动播放内容（轮播、演示）超过 5s 必须给播放/暂停与上一张/下一张，并在 focus、hover、离屏、标签页隐藏时停止
- tooltip：hover 延迟 800–1000ms、focus 延迟 0ms（两者相等 = 判失败）
- ❌ 反例：给列表每一行都加悬浮抬升 + 阴影过渡，长列表滚动掉到 20fps ｜ ✅ 正例：列表行只做 100ms 底色变化，抬升只留给卡片式入口

**动作 7：验收（先把手动复现写清，再谈可选证据）**
- 每个动效写清 3 步手动复现：怎么触发 → 该看到什么 → 怎么复位（例：点「保存」→ 按钮内打勾 300ms 后恢复 → 刷新页面），并把复现结果（真实命令输出或文件路径）写进 docs/MOTION.md
- ❌ 反例：只写一句"已检查，不闪" ｜ ✅ 正例：3 步操作写清 + 实际看到的现象（带时间读数或文件路径）
- 以下只在 L 档或用户明确要求时做：`Win + G` 录屏 5 秒，肉眼确认没有跳变、没有闪烁；DevTools Performance 录 3 秒，Frames 里没有红色长帧、Console 无强制同步布局警告

**动作 8：演示与投屏产物（只在这类产物上用；产品 UI 不走这一档）**
- 进入可以更长：入场 400–600ms、过渡 160–600ms、位移 ≤24px；自动播放的总时长 ≤8s，且必须能给暂停；用户没要求播放就默认静态
- 正文 ≥18px、caption ≥16px、meta ≥14px；48px 字号只给展示型标题
- 截图与导出必须确定性：截图前把动效停在终态，禁止用"等它播完再截"当验收

**动作 9：跑得动的动效自查（在项目根跑；非开发者只看退出码：exit 1 = 本卡未完成。按钮动效 ≥6 种、时长六类齐、缓动 ≥4、降级存在且带正向前置才算过）**
变量名一律 ASCII：Windows PowerShell 5.1 读无 BOM 的 .ps1 时中文变量名会报『字符串缺少终止符』；脚本必须存成 UTF-8 带 BOM。
```powershell
$m = 'docs/MOTION.md'; $l = @(Get-Content $m -Encoding UTF8); $btn = @($l | Where-Object { $_ -match '^\| (B[0-9]|按下缩放|上浮|颜色阶跃|涟漪|图标位移|无动效)' }).Count; $dur = @($l | Where-Object { $_ -match '^\| (hover|press|enter|exit|page|skeleton|进入|退出|页面|骨架屏)[^|]*\| *[0-9]' }).Count; $ease = @($l | Where-Object { $_ -match 'cubic-bezier' }).Count; $off = @($l | Where-Object { $_ -match 'prefers-reduced-motion: reduce' }).Count; $nopref = @($l | Where-Object { $_ -match 'prefers-reduced-motion: no-preference' }).Count; "MOTION.md 行数 $($l.Count)（要求 ≤100）"; "按钮动效行数 $btn（要求 ≥6）；时长行数 $dur（要求 ≥6）"; "缓动行数 $ease（要求 ≥4）；降级行数 $off（要求 ≥1）；正向前置行数 $nopref（要求 ≥1）"; if ($l.Count -gt 100 -or $btn -lt 6 -or $dur -lt 6 -or $ease -lt 4 -or $off -lt 1 -or $nopref -lt 1) { Write-Host '[FAIL] 本卡自查未过'; exit 1 } else { Write-Host '[OK] 本卡自查通过' }
```

**禁令（违反任意一条 = 本轮输出作废）：**
- 禁止超过 400ms 的动效；禁止动画阻塞交互（动效期间按钮必须仍可点，或明确禁用并给原因）
- 禁止全屏弹跳、闪烁、无限循环的装饰动效（骨架屏除外）
- 禁止 `transition: all`、禁止预防性 `will-change`；**禁止用 `animationend`/`transitionend` 决定状态**
- 禁止状态切换用回弹缓动（bounce/overshoot）；禁止同一元素叠多个悬停效果
- 禁止 hover-only 的动效（触屏与键盘用户必须有等价反馈）
- 禁止只写 `reduce` 分支而漏掉 `no-preference` 正向前置
- ❌ 反例：保存成功后全屏撒花 1.2 秒，期间按钮点不动 ｜ ✅ 正例：按钮内 300ms 打勾 + 3s Toast，交互全程可用
