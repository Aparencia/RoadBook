## ② 执行

**动作 1：时长表（六类写死，超过就是卡顿）**

| 场景 | 时长 | 说明 |
| :-- | :-- | :-- |
| hover | 100ms | 悬停变色、图标亮起 |
| press | 50ms | 按下反馈必须比悬停快，手感才"跟手" |
| enter | 150–200ms | 进场：弹层、抽屉、Toast 出现 |
| exit | 100–150ms | 退场必须比进场快，用户已经决定了 |
| page | 200–300ms | 页面转场，禁止超过 300ms |
| skeleton | 1200ms | 骨架屏循环一轮；不随内容长度变化 |

**动作 2：四条缓动曲线（只许用这四条，别自创）**

| 名称 | cubic-bezier | 用途 |
| :-- | :-- | :-- |
| standard 标准 | `cubic-bezier(0.2, 0, 0, 1)` | 通用位移、尺寸变化 |
| decelerate 减速 | `cubic-bezier(0, 0, 0.2, 1)` | 进场（快起步、慢收尾） |
| accelerate 加速 | `cubic-bezier(0.4, 0, 1, 1)` | 退场（慢起步、快离开） |
| emphasized 强调 | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 成功反馈、一次性强调；一屏最多一次 |

**动作 3：按钮动效选项（≥6 种，按场景挑一种，不要叠着用）**

| 选项 | 适用场景 | 时长 | 缓动 | 一行 CSS | 禁忌 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| B1 按下缩放 | 所有可点元素的基础反馈 | 50ms | standard | `.btn:active { transform: scale(.97) }` | 缩小超过 0.95 会像塌陷 |
| B2 悬停抬升 | 卡片式按钮、可点卡片 | 100ms | standard | `.btn:hover { transform: translateY(-1px); box-shadow: var(--shadow-2) }` | 抬升超过 2px 会晃；列表行内按钮禁用 |
| B3 颜色阶跃 | 次级按钮、纯文字按钮 | 100ms | standard | `.btn:hover { background: var(--color-brand-hover) }` | 主按钮按下后必须能回到原色，禁止只变不加过渡 |
| B4 波纹扩散 | 移动端主按钮、触屏列表项 | 200ms | decelerate | `transform: scale(0); animation: ripple 200ms cubic-bezier(0,0,0.2,1) forwards` | 桌面端禁用（鼠标没有触点）；一屏最多一处 |
| B5 图标位移 | 带箭头的"下一步/提交" | 150ms | standard | `.btn:hover .icon { transform: translateX(2px) }` | 位移超过 4px 会挤出按钮；图标不能换位 |
| B6 不动 | 表格行内操作、批量操作、低端机 | 0ms | — | `.btn { transition: none }` | 禁止用它跳过 B1 的按下反馈（按下必须有反馈） |

**动作 4：微交互清单（十项，每项都要有"触发 → 表现 → 时长"）**

| 微交互 | 触发 | 表现 | 时长 |
| :-- | :-- | :-- | :-- |
| 悬停 | 指针进入 | 底色或描边变化（不加位移） | 100ms |
| 按下 | 指针按下 | 缩放 0.97 或颜色加深 | 50ms |
| 聚焦环 | Tab 进入 | 2px 主色外发光，必须可见 | 0ms（瞬时） |
| 按钮内加载 | 点击后 | 文案换进行时 + 按钮内 spinner，宽度锁定 | 200ms 起，随请求结束 |
| 骨架屏 | 首屏请求发出 | 灰色块循环扫光 | 1200ms/轮 |
| Toast 进出 | 写操作返回 | 进场减速、退场加速，3s 后自动消失 | 进 150ms / 出 100ms |
| 列表增删 | 提交或删除成功 | 新行高度从 0 展开、删除行淡出 | 200ms |
| 折叠展开 | 点击标题 | 高度过渡；内容超过一屏时改为直接切换 | 200ms |
| 数字变化 | 数值更新 | 只做透明度切换，禁止滚动数字 | 150ms |
| 成功打勾 | 保存成功 | 描边画出勾，只播一次 | 300ms |

**动作 5：降级（晕动症与低端机，写死不许绕过）**
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: .01ms !important; transition-duration: 100ms !important; }
  .btn:hover, .btn:active { transform: none; }
}
```
开启后只保留 ≤100ms 的透明度或颜色变化；位移、缩放、旋转、视差全部关闭，功能一个都不能少。

**动作 6：性能预算（超了就是 bug，不是"稍慢"）**
- 只动 `transform` 与 `opacity`；禁止动 `width`/`height`/`top`/`left`/`margin`（会触发重排）
- 单次位移 ≤8px；超过 8px 改用淡入淡出
- 目标 60fps（每帧 ≤16.7ms）；掉帧就砍动效，不许砍功能
- 单次动效 ≤300ms；循环动效只允许骨架屏一种
❌ 反例：给列表每一行都加悬浮抬升 + 阴影过渡，长列表滚动掉到 20fps
✅ 正例：列表行只做 100ms 底色变化，抬升只留给卡片式入口

**动作 7：验收（先把手动复现写清，再谈可选证据）**
- 每个动效写清 3 步手动复现：怎么触发 → 该看到什么 → 怎么复位（例：点「保存」→ 按钮内打勾 300ms 后恢复 → 刷新页面），并把复现结果（真实命令输出或文件路径）写进 docs/MOTION.md
- ❌ 反例：只写一句"已检查，不闪" ｜ ✅ 正例：3 步操作写清 + 实际看到的现象（带时间读数或文件路径）
- 以下只在 L 档或用户明确要求时做：`Win + G` 录屏 5 秒，肉眼确认没有跳变、没有闪烁；DevTools Performance 录 3 秒，Frames 里没有红色长帧、Console 无强制同步布局警告

**动作 8：跑得动的动效自查（在项目根跑；非开发者只看退出码：exit 1 = 本卡未完成。按钮动效 ≥6 种、时长六类齐、缓动 ≥4、降级存在才算过）**
变量名一律 ASCII：Windows PowerShell 5.1 读无 BOM 的 .ps1 时中文变量名会报『字符串缺少终止符』；脚本必须存成 UTF-8 带 BOM。
```powershell
$m = 'docs/MOTION.md'
$l = @(Get-Content $m -Encoding UTF8)
$btn = @($l | Where-Object { $_ -match '^\| (B[0-9]|按下缩放|上浮|颜色阶跃|涟漪|图标位移|无动效)' }).Count
$dur = @($l | Where-Object { $_ -match '^\| (hover|press|enter|exit|page|skeleton|进入|退出|页面|骨架屏)[^|]*\| *[0-9]' }).Count
$ease = @($l | Where-Object { $_ -match 'cubic-bezier' }).Count
$off = @($l | Where-Object { $_ -match 'prefers-reduced-motion' }).Count
"MOTION.md 行数 $($l.Count)（要求 ≤70）"
"按钮动效行数 $btn（要求 ≥6）；时长行数 $dur（要求 ≥6）"
"缓动行数 $ease（要求 ≥4）；降级行数 $off（要求 ≥1）"
if ($l.Count -gt 70 -or $btn -lt 6 -or $dur -lt 6 -or $ease -lt 4 -or $off -lt 1) { Write-Host '[FAIL] 本卡自查未过'; exit 1 } else { Write-Host '[OK] 本卡自查通过' }
```

**禁令（违反任意一条 = 本轮输出作废）：**
- 禁止超过 400ms 的动效；禁止动画阻塞交互（动效期间按钮必须仍可点，或明确禁用并给原因）
- 禁止全屏弹跳、闪烁、无限循环的装饰动效（骨架屏除外）
- ❌ 反例：保存成功后全屏撒花 1.2 秒，期间按钮点不动 ｜ ✅ 正例：按钮内 300ms 打勾 + 3s Toast，交互全程可用
