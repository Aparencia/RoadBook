$spec = 'docs/specs/2026-10-05_slug'   # 先赋值再调用；换成 今天日期_功能slug

节标题逐字 `## 外部方案`；节内按 ①~⑤ 五小节写，每小节末尾一行"结论"。

**轮子先行五查（逐条给可判定证据；每个数字跟链接，估出来的数标 `⚠️ 估算：依据`）**

**① 有没有**：先写下 3 个检索关键词原文（主称 + 两个同义/别称），每个关键词在 GitHub / npm / PyPI（或按栈对应的包管理器）各搜一次；候选给 3 个（不足 3 个按实际数给），每个贴链接 + 一句话它做什么。
三个关键词都没有可用候选 → 该小节原文写"三个关键词均无可用候选"，不许留空。
❌ 反例："搜了一下，没有合适的"（没有关键词原文、没有链接、没有候选数）
✅ 正例："关键词原文：markdown table formatter；候选 1：https://github.com/x/y（最后提交 2026-08-14）"

**② 活不活**：每个候选给三项里至少两项——最后提交日期 / 最近发版 / 是否 archived 或 deprecated，逐项跟链接。
❌ 反例："看起来还在维护"（没有日期、没有链接）
✅ 正例："最后提交 2026-08-14（https://…/commits）；最近发版 v3.2.1（https://…/releases）；未 archived"

**③ 能不能用**：打开仓库根的 LICENSE 原文，写许可证名 + 两项义务：是否要求开源 / 是否可商用。
**无 LICENSE / GPL / AGPL / SSPL → 停下问人**（这类许可证会把我们的代码一起拽进开源义务）；问人前不许接入、不许写进依赖清单。
❌ 反例：README 写 MIT 就当 MIT（没打开 LICENSE 原文）
✅ 正例："LICENSE 原文 = Apache-2.0（链接）：不要求开源、可商用、需保留 NOTICE"

**④ 合不合**：引进来的代价四项逐条给——依赖树条数 / 体积 / 与现有栈冲突 / 是否需要常驻服务。
```powershell
$pkg = 'date-fns'   # 本次候选包名，先赋值再调用；按实际包管理器换命令
npm view $pkg dependencies dist.unpackedSize --json
```
❌ 反例："应该不大"（没有数字）
✅ 正例："依赖树 0 条、解包 1.2 MB（命令输出贴回执）、与现有栈无冲突、无常驻服务"

**⑤ 值不值**：两列并列 + 一句话结论——自研估行数 ‖ 接入估改动面。
❌ 反例："接入成本低，建议用现成的"（成本低在哪一列？）
✅ 正例："自研估 320 行（⚠️ 估算：依据 = 3 个解析分支 × 约 100 行）‖ 接入估改 4 个文件、加 1 个依赖；结论：接入"

**判定三值（必须落一个，不许含糊）**

| 判定 | 什么时候落这个值 | 必做动作 |
| :-- | :-- | :-- |
| 接入现成 | 五查全过 | 按"引入新依赖"计入档位（通常 L 档）；同批走 2-1 的"新依赖三查" |
| 抄思路自研 | 许可证允许，且只需要它的算法/结构/命名 | 写清抄了什么、许可证是否允许、抄的部分落在哪个文件 |
| 自研 | 五查里至少一条不过 | 逐条对应是哪一条不过（不许只写"不合适"） |

**来源纪律（每条数字都按这个口径写）**
① 只认官方来源：官方仓库的 tag / release / 提交记录、包页面、LICENSE 原文。
② 博客、问答站、模型记忆、训练数据不算依据，只能用来定位线索，必须回到官方原文核对。
③ 官方查不到 → 写 `UNVERIFIED` + 查了什么 + 为什么给不出结论；禁止"应该没问题"这类含糊对冲。
④ star 数只作线索、不作依据；每个数字后面跟链接，估出来的数标 `⚠️ 估算：依据`。
⑤ 检索日期写当天（YYYY-MM-DD）；查不到写"未查到公开数据"。

**留痕（被否的轮子一个不许丢）**
每个被否的候选进拒绝台账一行：`日期 | 提案 | 否决理由 | 既往请求编号`，写进 `docs/decisions/` 对应文件或 `docs/pool/IDEAS.md` 的"已否"段。
同一提案第二次出现**先读台账**，把上次的否决理由原文贴出来再讨论；禁不带台账重开一轮。

**与准入的分工**：普通包 / 库 / SaaS 走本卡；第三方技能、插件、MCP server、外部 CLI 走 7-9 准入（人裁决 + 机检）。本卡只回答"要不要用"，不代替准入。

**禁令：**
- 禁止跳过检索直接判"自研"（三个关键词没搜完 = 本轮作废）
- 禁止拿 star 数、博客、模型记忆当依据
- 禁止在许可证不明（无 LICENSE / GPL / AGPL / SSPL）时接入
- 禁止写含糊判定（三值必须落一个）
- 禁止在本卡写任何业务代码
