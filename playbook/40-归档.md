## ② 执行

**归档十查（逐条执行，逐条回执；S 档任务：十查仍逐条执行，但回执合并为一段知会）：**

**① registry 回写核对（diff 驱动，禁止凭记忆回答"改过吗"）**：
   - a. `git diff --name-only <起点锚点>..HEAD` + 变更符号提取 → **变更清单**（ground truth；起点锚点从 STATE.md 读）
   - b. 清单按域分类（UI/表/接口/配置/依赖），每个变更项 → registry 对应行标记：已回写 ✓ / 不适用 —（原因）/ 未处理 ○（**当场补**，○ 不许留空）

**② 教训沉淀**：本次踩坑了吗？有 → 写 `docs/lessons/<日期>_<主题>.md`（≤12 行：现象→根因→修法→下次怎么定位）。**先查重**：同症状更新旧卡，不建新卡。

**③ 债务滚动**：新债务/被否方案 → 登记 `docs/TECH_DEBT.md`（open）；本次已清偿的 → 改 closed 并附证据（commit 哈希/文件路径）。

**④ 版本记录**：根 `CHANGELOG.md` 顶部"未发布"节追加一行（新增/变更/废弃/修复 四类之一，一行一条）。

**⑤ 常驻文档过期检查**：AGENTS.md 有过时规则吗（删，保持 ≤200 行）？README 启动命令跑得通吗？docs/ARCHITECTURE.md 模块图与实际目录一致吗？docs/RUNBOOK.md 部署方式变了吗？——不一致就更新。

**⑥ 防膨胀执行**：lessons/ 与 decisions/ 各超 30 张 → 最旧且 90 天无引用的移入 `docs/archive/`；specs/ 里超 30 天未动的任务 → 提示用户归档。

**⑦ 工作区清理**：
```powershell
git mv docs/specs/<本次任务目录> docs/archive/<今日>-<slug>
```
债务滚动快照写入 `docs/archive/<今日>-<slug>/tech-debt.md`（closed 数 + carried 数 + 关键项）。无 git 环境用 Move-Item 并在回执注明"历史链代价"。

**⑧ 孤儿三查（文件级 / 代码级 / 文档级双向 + 未登记；以 git 为基准，跑脚本不靠记忆）**：

```powershell
powershell -File orphans.ps1
git ls-files | Measure-Object -Line | Select-Object -ExpandProperty Lines
```
（第二条只作参考计数；口径以 orphans.ps1 汇总行为准，**汇总行原样贴进回执**。）

   - a. **文件级孤儿**：`git ls-files` 里零引用的文件（任何 .md/.ps1/.json/源码里都搜不到其文件名，且不在入口清单里）
   - b. **代码级孤儿**：零引用的导出/函数/类——零依赖先用文本搜索；有依赖后再上 knip / vulture / tsc --noUnusedLocals。**只报不拦，观察两轮再升为门禁**
   - c. **文档级双向**：文档提到的路径在磁盘不存在（幽灵）+ 磁盘存在但任何文档都没提到（反向幽灵）；被触碰域的 registry 行照旧做"行 → 代码"存在性 grep（APIS 路由 / DATA_DICT 字段在 src 里 grep），命中零 = 过期文档
   - d. **未登记文件**：不在 `docs/registry/COMPONENTS.md` 里的文件

**处置规则（每条孤儿必须落进下列三类之一，"什么都不做"不允许）：**
   - 删除——本次能安全删的，随本次归档提交一起走
   - 登记为技术债——写进 `docs/TECH_DEBT.md`
   - 在 COMPONENTS.md 补登记
   - ❌ 反例：扫出一堆孤儿，回执写"已了解，下轮处理"（= 什么都没做）
   - ✅ 正例：每条有归属，回执给出计数"删除 x / 登记 TD x / 补登记 x"，相加 = 汇总行总数

**⑨ 原子提交**：
```powershell

```
**禁止 `git add -A` / `git add .`**。提交前展示 `git status` 待用户确认。

**远端同步（归档收尾必做）**：`git push origin main`（推送前确认 `git status --porcelain` 里没有 `.env` / `*.key` / `*.pem`——推出去不可逆）。远端是唯一抗磁盘故障的历史；没有远端 → 记一行"本地-only"（连续两个归档周期不推 = 43 卡信号 10）。
