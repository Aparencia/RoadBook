# 卡 3-5 · 色彩与风格（界面动工前定死取值）

## ① 开工确认

收到开工指令后，先回执以下五项再动手（缺项不开始）：

1. **任务复述**：用一句人话说清"这套色和字号给谁看、覆盖哪些页面、什么算能用"。
2. **假设清单**：逐条写"我假设 X；若错则 Y 失效"（例：我假设已有品牌主色；若错则主色整套换掉再重算对比度）。能从 package.json、SCOPE.md 查到的不许写进假设。
3. **澄清问题（≤5 个，能删则删）**：只问决定取值的硬信息——有没有必须沿用的品牌色？主要给手机还是桌面看？要不要暗色模式？有没有品牌字体？
4. **本卡检查清单原文（开工时逐字复述这十三条，收工前逐条勾）**：
   - [ ] ① 中性色 10 阶 50–900 给全，每阶一个十六进制值，并写生成规则

   - [ ] ③ 语义色四类成功／警告／危险／信息，浅色与暗色两套值
   - [ ] ④ 对比度门禁写死并给出可跑命令：正文 ≥4.5:1、大字 ≥3:1、界面边界 ≥3:1
   - [ ] ⑤ 字号阶梯 12/14/16/20/24/32/40，配行高与字重

   - [ ] ⑦ 圆角 4/8/12/999、1px 边框、三级阴影都给具体 CSS 值
   - [ ] ⑧ 命名规则 `--color-<语义>-<层级>` 与浅色／暗色映射表

## ② 执行

**合理化红旗表（开工时逐条念；出现任一条 = 停下按本卡补做）**

| 你会想 | 事实 |
| :-- | :-- |
| 颜色直接写在组件里更快 | 组件里出现裸色值 = 主题换不了、暗色模式必崩；本卡只认语义 token |
| 主色多铺几处更统一 | accent 覆盖任一视口超过 5% 即判失败；accent 是荧光笔，不是色块 |
| 暗色模式把颜色反过来就行 | 反相会毁掉对比度与层级；暗色要重算六条（底色、字重、chroma、elevation、色相、正文色） |
| 字体先用 Inter，后面再换 | 禁用清单里的字体会让界面立刻读作模板；换字体是取值决定，不能留到后面 |

**动作 4：对比度门禁（WCAG 2.1 AA 写死，超限一律改取值不改门禁）**
- 正文（<18px 或 <14px 粗体）对背景 ≥ **4.5:1**
- 大字（≥18px 或 ≥14px 粗体）、图标、图表关键元素 ≥ **3:1**
- 界面边界（输入框描边、卡片描边、分隔线）对相邻面 ≥ **3:1**；通用描边取值 `#6C757D`（对白 4.69:1、对 50 底色 4.41:1、对暗底 3.29:1）；状态禁止只靠颜色区分，必须同时有图标或文字
- ❌ 反例：把错误文字改成红色就算提示（色盲用户看不出来）｜ ✅ 正例：红字 + 图标 + "保存失败"字样三重表达
- 占位文字与辅助说明同样按正文门禁 ≥ **4.5:1**，不许比正文低（placeholder / helper 是最常被放过的一类）
- 焦点环对元素自身与所在页面底色都要 ≥ **3:1**；任何写了 `background` 的规则必须在同一规则里写 `color`，否则暗色区块会出现同色文字
- 主色填充上的文字必须引用配对的 `--color-brand-ink`（语义色同理各自配对 `-ink`），禁止硬编码 `color: white`；填充与文字的 OKLCH 亮度差 <5% 且 chroma 差 <0.05 即判失败

**动作 5：跑得动的对比度自检（把颜色换成自己的取值；任一行低于门禁即改色重跑）**
变量名一律 ASCII：Windows PowerShell 5.1 读无 BOM 的 .ps1 时中文变量名会报『字符串缺少终止符』；脚本必须存成 UTF-8 带 BOM。
```powershell
function Get-CR($a, $b) {
  $L = { param($h) $c = @(1,3,5) | ForEach-Object { [Convert]::ToInt32($h.Substring($_,2),16)/255 }; $v = $c | ForEach-Object { if ($_ -le 0.03928) { $_/12.92 } else { [Math]::Pow(($_+0.055)/1.055,2.4) } }; 0.2126*$v[0]+0.7152*$v[1]+0.0722*$v[2] }
  $x = & $L $a; $y = & $L $b; [Math]::Round((([Math]::Max($x,$y)+0.05)/([Math]::Min($x,$y)+0.05)),2)
}
"body  #343A40 on #FFFFFF  " + (Get-CR '#343A40' '#FFFFFF')
"large #495057 on #FFFFFF  " + (Get-CR '#495057' '#FFFFFF')
"bound #6C757D on #FFFFFF  " + (Get-CR '#6C757D' '#FFFFFF')
"focus #2563EB on #FFFFFF  " + (Get-CR '#2563EB' '#FFFFFF')
"focus #2563EB on #F7F8FA  " + (Get-CR '#2563EB' '#F7F8FA')
"place #6C757D on #FFFFFF  " + (Get-CR '#6C757D' '#FFFFFF')
```
判定：body／place 两行 ≥4.5；large／bound 两行 ≥3；focus 两行（元素底色与页面底色）都要 ≥3。

**动作 6：字号阶梯（`--font-size-*`；中文优先字体栈：`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`；正文行高 1.5、标题行高 1.25；行宽 45–75 字符，超出用 `max-width: 65ch` 收口）**

| 档 | 字号 | 行高 | 字重 | 用途 |
| :-- | :-- | :-- | :-- | :-- |
| xs | 12 | 1.5 | 400 | 辅助说明、表格脚注 |
| sm | 14 | 1.5 | 400/500 | 表格正文、表单标签 |
| base | 16 | 1.5 | 400 | 正文默认 |
| lg | 20 | 1.5 | 500 | 卡片标题、小节标题 |
| xl | 24 | 1.25 | 600 | 页面标题（h1） |
| 2xl | 32 | 1.25 | 600 | 营销区标题、大数字 |
| 3xl | 40 | 1.25 | 700 | 首屏主标题（一页最多一处） |

**动作 7：间距与布局（`--space-*`，4px 基线，只许取这八档）**
`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`。相邻文字块 4–8，卡片内边距 16–24，卡片之间 24–32，页面区块之间 48–64。❌ 反例：`margin: 13px`、`padding: 5px` 这类手填值 ｜ ✅ 正例：一律写 `var(--space-3)`（即 12）

**动作 8：圆角、边框、阴影（`--radius-*` / `--shadow-*`；圆角 `4` 输入框 / `8` 卡片与按钮中档 / `12` 弹层与大按钮 / `999` 头像与胶囊标签；边框统一 `1px solid var(--color-neutral-300)`；聚焦用 `outline: 2px solid var(--color-focus); outline-offset: 2px`，禁止用 `box-shadow` 外发光冒充焦点环；阴影三级直接用）**
```css
--shadow-1: 0 1px 2px rgba(33, 37, 41, .08);
--shadow-2: 0 2px 8px rgba(33, 37, 41, .12);
--shadow-3: 0 8px 24px rgba(33, 37, 41, .16);
```
同一个元素只挂一级阴影，禁止两级叠加；浅色底禁止纯黑投影与彩色辉光，暗色面上的层级用亮度差而不是阴影。
圆角只选一套并全页锁定（上面 4/8/12/999 就是一套）；混用必须在文档里写成文规则。

**动作 9：颜色 token 纪律（组件里只许出现 token 名）**
1. 命名按角色不按外观：`--color-brand`／`--color-accent`／`--color-bg-page`／`--color-bg-surface`／`--color-text-primary`／`--color-border`／`--color-focus`／`--color-<语义>`／`--color-<语义>-ink`；禁止 `--blue-500` 这类把外观写进名字的 token。
2. 组件样式里 0 处颜色字面量：`#hex`、`oklch()`、`rgb()`、`hsl()` 只允许出现在 `:root` 与 `[data-theme="dark"]` 主题块内。
3. 字体族同理：任何 `font-family` 必须引用 `--font-*` token。
4. accent 唯一：一个界面最多 2 个 accent，主 accent 在任何视口面积占比 ≤3%（硬上限 5%）；accent 当荧光笔用（激活态、焦点环、hover 下划线、主 CTA 边框或文字），不填充大按钮、不整节上色。
5. 60-30-10：中性底色 60%、次级面与文字 30%、accent 10% 以内；比例写进 `docs/DESIGN_TOKENS.md`。
6. 禁止项：纯 `#000000` 与纯 `#ffffff` 作基色；三色渐变（只用双停）；紫→蓝／青→品红渐变；渐变文字（含 `background-clip: text`）；`#6366f1` 与紫蓝组合；浅底上的纯黑投影与彩色辉光。
7. 中性色在 OKLCH 下 chroma 取 0.005–0.015 并向主色相偏（零 chroma 的平灰是 AI 特征）；工具链不支持 OKLCH 时用十六进制，但保持同一条色相偏移规则并在表里注明。

❌ 反例：`background: linear-gradient(135deg, #6366f1, #8b5cf6)` 铺满 hero，组件里再写 `color: #333`
✅ 正例：`background: var(--color-bg-page)`；accent 只用在激活的导航项与焦点环上，占屏面积 2%

**动作 10：字体族与排版纪律**
1. 字体族 ≤3：display + 正文 + 至多 1 个 outlier；outlier 全页 ≤2 处且只承担一种角色（如 wordmark + 首屏数字）。
2. 禁用默认字体作 display：Inter、Roboto、Open Sans、Lato、Poppins、Montserrat、DM Sans、system-ui、Arial、Helvetica、Merriweather、Lora、Courier New、Consolas。Inter 只在用户明确要求中性风格或公共部门无障碍优先时可用，默认换 Geist／Outfit／Cabinet Grotesk／Satoshi。
3. 正文比例从 1.25／1.333／1.5／1.618 里选一个写进 token（默认 1.25），禁止混用两套比例。
4. 行高随字号：display 1.05–1.2（首屏贴合场景可到 1.0–1.1）、正文 1.5–1.65；全大写 display 标题行高下限 1.0。
5. display 字号上限 88 px（重度主题 96 px），≤12 字符的单行单词可到 112 px；正文最小 16 px（低于 16 px 时移动端浏览器会自动缩放输入框）。
6. 标题必须是 roman：任何 heading／display 用斜体即判失败（含标题内的 `<em>`／`<i>`）；斜体只允许正文行内强调。
7. 行宽 45–75 字符（`max-width: 65ch`），中文按每行 30–40 字收口；移动端正文 35–60 字符。

**动作 11：层级与 z-index（七档具名，禁止随手 9999）**

| token | 值 | 用于 |
| :-- | :-- | :-- |
| `--z-base` | 1 | 普通内容 |
| `--z-raised` | 10 | 卡片抬升、吸顶元素下层 |
| `--z-dropdown` | 100 | 下拉、菜单、popover |
| `--z-sticky` | 200 | 吸顶导航、工具条 |
| `--z-modal` | 400 | 弹窗与遮罩 |
| `--z-toast` | 500 | 全局提示 |
| `--z-tooltip` | 600 | 悬浮说明 |

**动作 12：暗色模式六条（两套值，不是反相）**
1. 底色：`--color-bg-page` 亮度 12–18%（不用纯黑）；面层 `--color-bg-surface` 亮度 +3% 起，每级 elevation 约 +3%。
2. 文字：正文与标题亮度 92–96%（不用纯白）。
3. 字重：正文比浅色模式降 50 单位（400 → 350），防止亮字在暗底显得更粗。
4. accent：chroma 降 0.02–0.04、亮度提 5–10%（浅色下的 accent 在暗底会刺眼）。
5. 色相：明暗两套的 hue 不许改变，只动亮度与 chroma。
6. 图片与插画：暗色下降低亮度或加 1 px 描边，禁止直接沿用浅色截图。

❌ 反例：暗色模式 = `filter: invert(1)` 或把浅色值逐个反相 → 语义色全糊、图片变负片
✅ 正例：`:root` 与 `[data-theme="dark"]` 各写一套语义 token，色相不变，亮度与 chroma 按上面六条调

**动作 13：演示／投屏分支（最小档，只在产物是幻灯片／投屏页时用）**
- 正文字号 ≥18 px，caption ≥16 px，meta／页码 ≥14 px；48 px 只用于展示型大标题。
- 字号越大字重越细（大标题用 500 而不是 800），避免远看糊成一团。
- 对比度仍按动作 4 的门禁，且不压线（投影仪会再损失一档对比度）。
- 本分支只调这几个数；版面几何、主题预设、图片槽位不进本卡。

**动作 15：本卡产物自查（在项目根跑；非开发者只看退出码：exit 1 = 本卡未完成。10 阶齐、四类语义齐、7 个 token、0 裸加粗色值、六个新槽位齐、行数 ≤110 才算过）**
```powershell
$t = 'docs/DESIGN_TOKENS.md'
$l = @(Get-Content $t -Encoding UTF8)
$text = $l -join "`n"
$neutral = @($l | Where-Object { $_ -match '^\| [0-9]{2,3} \|' }).Count
$sema = @($l | Where-Object { $_ -match 'success|warning|danger|info' }).Count
$tok = @($l | Where-Object { $_ -match '--color-[a-z-]+' }).Count
$raw = @($l | Where-Object { $_ -match '\*\*#[0-9A-Fa-f]{6}\*\*' }).Count
$need = @('--color-focus','--color-brand-ink','outline-offset','--z-modal','[data-theme="dark"]','60-30-10')
$miss = @(); foreach ($n in $need) { if ($text -notmatch [regex]::Escape($n)) { $miss += $n } }
"行数 $($l.Count)（要求 ≤110）｜中性阶 $neutral（要求 ≥10）｜语义色 $sema（要求 ≥4）"
"token $tok（要求 ≥7）｜裸加粗色值 $raw（要求 0）｜新槽位未命中 $($miss.Count) -> $($miss -join ',')（要求 0）"
if ($l.Count -gt 110 -or $neutral -lt 10 -or $sema -lt 4 -or $tok -lt 7 -or $raw -ne 0 -or $miss.Count -gt 0) { Write-Host '[FAIL] 本卡自查未过'; exit 1 } else { Write-Host '[OK] 本卡自查通过' }
```

**禁令（违反任意一条 = 本轮输出作废）：**
- 禁止正文用纯黑 `#000000`（对白 21:1 刺眼且丢层级），正文主色就用 800 档 `#343A40`；禁止只用颜色表示状态
- 禁止写 `#3a7` 这类三位缩写与组件里的裸色值；禁止在 DESIGN_TOKENS.md 里写"待定/后续再补"，缺的写 `N/A（理由）`
- 禁止用 `box-shadow` 或 `border` 冒充焦点环；禁止焦点环对页面底色低于 3:1
- 禁止主色填充上硬编码 `color: white`（必须用 `--color-brand-ink`）；禁止写了 `background` 却不写同规则 `color`
